Overview

A shop window for open models — with the GPUs behind the counter.

Every model on this page has published weights and a licence you can read. Pick one, test it, then run it the way that suits your traffic: pay per token on shared serverless capacity, or reserve your own GPUs.

Choosing an AI model usually means reading a dozen model cards, guessing how much GPU memory it needs and then finding somewhere to host it. The XcellHost Model Catalog puts the short list in one place: who made the model, how big it is, how much text it can read at once, what it is good at and which licence it ships under — with a sample you can try before you commit.

Everything runs on the XcellHost Inference Cloud in Mumbai, so prompts, documents and outputs stay in India — useful when the DPDP Act 2023, a sector regulator or your own customers ask where data goes. You call models through an OpenAI-compatible API, pay in rupees on a GST invoice, and talk to a support team that has run infrastructure for Indian businesses since 1999.

    From shelf to production

    One model, six steps to a live endpoint.

    Scroll through what happens after you pick a card. The picture rebuilds itself at each step.

    01 · Discover
    1. 01

      Discover

      Filter 17 models by task, size, licence and tier. Every card lists the publisher, parameters, context window and modality, so the short list takes minutes.

    2. 02

      Try a sample

      Open the playground to see the kind of output each model type produces — chat, code, transcripts, vectors, images or safety verdicts. Samples are illustrative — ask us about testing with live traffic.

    3. 03

      Choose a tier

      Serverless: shared, autoscaling, billed per token. Dedicated: your own GPUs, fixed capacity, fine-tuned or custom weights. Many teams start serverless and move hot paths to dedicated.

    4. 04

      Deploy on GPUs

      For dedicated, we size the GPU — NVIDIA L4, RTX Pro 6000 or H200 — from the model's memory need, precision and expected concurrency, then load the weights in Mumbai.

    5. 05

      Integrate

      Point any OpenAI-compatible SDK at your XcellHost endpoint. Chat completions, embeddings and transcriptions use familiar request shapes, so existing code needs a new base URL and key.

    6. 06

      Govern

      Data stays in India, you decide who holds API keys, and we help you record which model and licence each workload uses — the paperwork a DPDP review or customer audit will ask for.
