KEY SMB CLOUD SERVICES

1. TALLY ON CLOUD
Source: https://xcellhost.cloud/tally-on-cloud
What it is: A hosted cloud workspace for Tally and TallyPrime that enables authorised accountants, auditors and branch teams to work with the same live business data remotely.
Who it suits: SMEs, accounting firms, multi-branch businesses and finance teams that need secure remote access to Tally without being tied to one office computer.
Customer benefits:
- Work from office, branch or home using authorised devices.
- Centralise the Tally environment so users work on the same live data.
- Scale the virtual server resources as user count and workload grow.
- Use a managed environment with support and migration assistance.
Published technical/service details:
- Tally private-cloud plans are shown for teams from 3–4 users through 51–75 users.
- Published plans show Windows Server 2025, SSD storage, dedicated IP, Acronis Cyber Protect Cloud endpoint security, Fortinet firewall/high availability and 24×7 support.
- The product page states backups every 8 hours; it also describes encrypted, ransomware-resistant backups. Confirm the final backup and SLA terms in the selected plan/contract.
- The site refers to Tier IV datacentres and support for Windows, Mac, Linux and iOS access.
Useful discovery questions: How many simultaneous Tally users are needed? Which Tally version and add-ons are used? Is data currently on a desktop/server? Which locations need access? Do users need printing, VPN or integration with other applications?

2. CLOUD BACKUP
Source: https://xcellhost.cloud/cloud-backup
What it is: Managed cloud backup for servers, endpoints, applications and business workloads, using Acronis Cyber Protect Cloud plans shown on the website.
Who it suits: Businesses needing recoverable copies of critical files, systems, Microsoft 365, virtual machines or databases without managing backup hardware themselves.
Customer benefits:
- Protection against accidental deletion, hardware failure, ransomware and data loss.
- Scheduled automated backups and configurable retention.
- Restore at file/folder level or recover a whole system to new/recovered hardware.
- Centralised backup protection across mixed workloads.
Published capabilities: full-image backup; file and folder backup; off-site cloud copies; encryption in transit and at rest; ransomware protection; bare-metal recovery. The page lists Windows, Linux, Hyper-V, VMware, Nutanix, Microsoft 365, Google Workspace, Exchange, SQL Server, Oracle, SAP HANA, AWS, Azure and Google Cloud among supported platforms/workloads.
Published package examples: storage tiers of 50 GB, 100 GB, 250 GB, 500 GB and 1 TB are shown with unlimited backup agents; final scope and pricing must be confirmed by quote.
Useful discovery questions: What must be protected? How much data is involved? What recovery time is acceptable? Do you need Microsoft 365 or server backup? How long must data be retained? Is a recovery test required?

3. CLOUD DRIVE
Source: https://xcellhost.cloud/cloud-drive
What it is: A business file storage, sync and collaboration service for centrally managed folders, controlled sharing and access across devices.
Who it suits: Teams replacing a file server or looking for an India-hosted, managed alternative for team file sharing and collaboration.
Customer benefits:
- Centrally managed team folders and role-based access.
- Secure external sharing links with password and expiry controls.

The public page states Indian data centres, 99.9% platform uptime SLA and 24×7 emergency support. Confirm contracted SLA and data location before purchase.
Published storage plans: pooled storage with unlimited users, shown from 250 GB to 5 TB. The page shows INR pricing excluding GST; final prices and optional services must be confirmed.
Useful discovery questions: How many users and how much storage? Do you need external sharing? What is currently used—file server, Google Drive or OneDrive? Are there data-residency or audit requirements?
