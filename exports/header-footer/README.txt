XCELLHOST HEADER + FOOTER — STANDALONE HTML / CSS / JAVASCRIPT

Open index.html in a browser. No Angular, npm installation or build is required.

FILES
index.html: Complete ready-to-open example.
header.html / footer.html: HTML fragments for use in other pages.
header.css / footer.css: Component styles.
styles.css: Shared styles, fonts and responsive overrides.
header-footer.js: Mega menus, hover categories, mobile accordion, Tools, login and theme controls.
navigation-data.js: Menu feature cards and Tools destinations.
config.js: Website destination (production by default).
assets/: Included local images and icon font.

LINKS
All navigation anchors point to the existing XcellHost pages.
Set XCELLHOST_SITE_URL in config.js to http://localhost:4200 for your local pages.
Menu labels and category buttons open menus; service cards and footer links navigate.
Search opens the website sitemap; Ask AI and Let's Talk open Contact; Join Us as Partner opens Partner Signup.
The video opens YouTube. The language link opens the English XcellHost website.
Fonts from Google and external services require an internet connection.

REUSE
Copy assets/ and the CSS/JS files alongside your page. Paste header.html and footer.html into the page and include the same stylesheet/script tags as index.html.
Keep the full files together so menu images and icons resolve correctly.
This package contains the header/footer, not the linked service pages or Angular overlays.
