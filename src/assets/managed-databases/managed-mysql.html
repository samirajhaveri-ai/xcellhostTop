What is managed MySQL?

Managed MySQL is a MySQL database that a provider runs for you — provisioning, patching, upgrades, backups, replication, monitoring and failover are handled, so your team works only with schemas and queries. XcellHost runs it as a standalone instance, an HA pair (Group Replication) or an InnoDB Cluster with read replicas, with binlog point-in-time restore and 30-day backup retention in Indian data centres.
