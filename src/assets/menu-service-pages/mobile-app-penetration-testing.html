Definition

What is mobile application penetration testing?

It is a security assessment that simulates real-world attacks against your Android and iOS applications to find exploitable weaknesses before someone with bad intent does. We use the OWASP Mobile Application Security Verification Standard (MASVS) as the testing baseline.

Static analysis

The app’s code and binaries are examined for hardcoded secrets, weak cryptography and unsafe configuration.

Dynamic analysis

The running app is observed and manipulated on real and rooted or jailbroken devices.

Backend & API testing

Every API the app calls is tested for authentication, authorisation and logic flaws.

What we look for

Common mobile application vulnerabilities

Thorough manual testing surfaces a wide range of weaknesses. These nine turn up most often.

01

Insecure data storage

Credentials, tokens or personal data kept in plain text in files, databases, logs or backups.

02

Weak server-side controls

Backend services that do not validate requests properly and trust the client too much.

03

Weak transport protection

Missing or bypassable TLS and certificate pinning that lets traffic be read or altered.

04

Unintended data leakage

Sensitive data exposed through clipboard, screenshots, analytics, keyboards or third-party SDKs.

05

Poor authorisation & authentication

Weak login, biometric bypass and users reaching data or functions that are not theirs.

06

Broken cryptography

Outdated algorithms, hardcoded keys and home-grown encryption that fails under scrutiny.

07

Client-side injection

SQL injection, WebView script injection and other attacks through data the app processes locally.

08

Decisions on untrusted input

Security checks driven by intents, deep links or parameters an attacker can control.

09

Improper session handling

Sessions that never expire, tokens that are predictable, and logouts that do not log out.

White box testing

03
Some knowledge

Grey box testing

A balanced approach that combines limited internal information, such as test accounts, with external testing techniques.
