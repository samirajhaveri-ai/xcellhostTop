    Overview · what is a virtual edge?

    Network appliances become software, and the edge becomes one box.

    Network functions virtualisation (NFV) takes jobs that used to need a dedicated box — routing, firewalling, SD-WAN, load balancing, VPN — and runs them as virtual network functions (VNFs) on standard servers. At a branch, one small server called a universal CPE (uCPE) can host several VNFs side by side. In the cloud, the same VNFs run as virtual machines next to your workloads. The model follows the ETSI NFV framework: shared infrastructure, the VNFs themselves, and an orchestration layer that deploys and lifecycles them.

    XcellHost designs the chain, sizes each VNF in vCPU and throughput, and runs it where it works best — on a uCPE at your site or in XcellHost cloud in our Tier IV data centre in Mumbai. It is vendor-agnostic: bring your own licence or let us source it, and we support leading vendors' virtual appliances*. Our NOC watches every VNF 24×7, applies changes through a template, and bills it all in INR with GST.
