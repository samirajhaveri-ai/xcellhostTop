Security posture

How we protect your data, end to end.

Our security program is built on layered defense, zero-trust access and continuous monitoring — operationalised through Microsoft 365 E5 security, Azure-native controls and documented policies.

Defense in depth

Layered controls across identity, endpoint, network, application and data — built on Microsoft 365 E5 security, Defender XDR and continuous SIEM monitoring.

Encryption by default

TLS 1.2+ in transit, AES-256 at rest. Customer secrets isolated in cloud-native key vaults with role-based access and audit logging.

Zero-trust access

MFA enforced for 100% of workforce identities. Conditional access, device compliance and least-privilege roles reviewed quarterly.

Continuous monitoring

24×7 SIEM aggregation of identity, endpoint, network and SaaS logs from our Mumbai SOC, triaged through documented runbooks.

Personnel security

Background checks for employees and contractors. Annual security-awareness training with documented completion tracking.

Documented program

Written information-security policy, vendor-management standard, incident-response plan and BCP/DR reviewed at least annually.

Vulnerability management

Continuous detection. Honest disclosure.

Our program focuses on continuous detection, prioritisation and remediation across endpoints, identity, cloud workloads and SaaS systems.

Continuous scanning

Defender Vulnerability Management runs continuously across enrolled endpoints, matching CVEs against installed software.

Cloud posture management

Defender for Cloud monitors every Azure subscription against the Microsoft Cloud Security Benchmark.

Endpoint detection & response

Defender for Endpoint provides EDR on 100% of managed devices, with automated isolation on high-severity detections.

SIEM correlation

Sentinel ingests identity, endpoint, network and SaaS logs; alerts are triaged through documented runbooks 24×7.

Patch management

Critical OS and browser patches within 14 days, high within 30, standard within 90 — tracked to closure.

Responsible disclosure
