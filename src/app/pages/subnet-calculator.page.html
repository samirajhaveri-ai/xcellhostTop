CIDR makes the boundary explicit

Understand the size of an IPv4 block before assigning addresses.

An IPv4 address contains 32 bits. The CIDR prefix tells you how many identify the network; the remaining bits define positions within the block. Increasing the prefix by one halves the number of addresses.

/24 · 256 addresses

255.255.255.0 mask, usually 254 conventional host slots.

/26 · 64 addresses

255.255.255.192 mask, usually 62 conventional host slots.

/30 · 4 addresses

255.255.255.252 mask, usually 2 conventional host slots.

Read RFC 4632 on CIDR, RFC 3021 on /31 links and the IANA special-purpose registry for addressing rules.

Start with an address. Finish with a clear plan.

    For example, 192.168.1.10/24. You can enter a host inside the block.

  2. Review the boundaries and host slots
