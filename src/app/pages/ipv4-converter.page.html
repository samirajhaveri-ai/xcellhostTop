Different notation. The same 32 bits.

IPv4 values can be represented without changing their underlying bytes.

The address 192.168.1.1 contains the bytes 192, 168, 1 and 1. Written in hexadecimal, those bytes are C0, A8, 01 and 01. Combined in network byte order, they form the unsigned decimal integer 3232235777.

Dotted decimal

Four decimal octets, each ranging from 0 through 255.

Binary

32 bits, usually displayed as four groups of eight.

Hexadecimal

Eight digits, with two hexadecimal digits per byte.
