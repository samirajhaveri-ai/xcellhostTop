school

Understand the document before using it

Syntax, presentation and application rules serve different purposes.

JSON describes values using a small set of tokens. Objects hold named members; arrays hold ordered entries. Strings, numbers, booleans and null can appear as values, including at the root.

Format

Put structural tokens on separate lines with consistent indentation. String contents and their escape sequences stay untouched.

Minify

Join tokens without optional whitespace. Quoted spaces are data and remain in the output.

Validate

Check grammar and completeness. Valid syntax alone does not prove that an API accepts the document or that its values are correct.

checklist

From raw input to usable JSON

Inspect, fix, format and reuse.

  1. Paste or open a document

    Use the input editor or choose a UTF-8 file. An example is available for a quick start.

  2. Pick the presentation

    Choose indentation for readable output, or minify when you need a compact payload.

  3. Review errors and warnings

    Jump to a syntax error and check duplicate names. Document statistics help reveal unexpected structure.

  4. Take the result with you

    Copy the complete output, download JSON or move the formatted text back to the input.
