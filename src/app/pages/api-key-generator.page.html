What makes a useful API key?

Random key material is one part of a complete authentication system.

An opaque API key is a random string that your service can register, validate and associate with a client’s permissions. This generator creates that random string. Your application controls what it authorizes, where it is accepted and when it expires.

Randomness

Each character is sampled uniformly from the selected alphabet using Web Crypto.

Entropy

The random length and alphabet size determine the estimated number of unpredictable bits.

Prefix

A readable environment or key-type label. It helps identification and contributes no secrecy.

format_list_numbered

Create keys in four steps

Choose, generate and move the result into your own system.

  1. Choose a character format

    Use Base62 for letters and numbers, hex for hexadecimal text, or the Base64url alphabet for URL-safe symbols.

  2. Set the random length and optional prefix

    The entropy estimate updates with your settings. Your prefix is added to the complete random part.

  3. Generate one key or a batch

    Create up to 100 keys with fresh randomness. Copy individual rows or the complete list.

  4. Register and manage your key

    Use your application’s credential process, protect the secret and assign only the permissions it needs.
