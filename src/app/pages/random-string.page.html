school

A random string starts with its character pool

Length and alphabet size determine the random search space.

This tool builds a pool of distinct characters from your selections and samples each position independently. Larger pools and longer strings create more possible outputs. A secure random source makes those selections unpredictable under normal browser operation.

Character pool

The distinct characters available at each position, after exclusions.

Random bits

Length × log₂(pool size). For example, 32 hex characters give 128 bits.

Uniform sampling

Each character has the same probability. Duplicate custom entries add no extra weight.

format_list_numbered

Generate strings in four steps

Start from a preset, or control the complete pool yourself.

  1. Choose a preset or character groups

    Use letters, digits and symbols, then add custom characters if needed.

  2. Set length, quantity and exclusions

    Use custom-only mode for an exact pool. Remove look-alike characters for easier manual reading.

  3. Review and generate

    Check the alphabet preview and estimated random bits, then create up to 100 strings.

  4. Copy or download

    Copy one string or the full batch. TXT and JSON downloads retain the complete output.
