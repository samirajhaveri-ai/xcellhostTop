Randomness helps. Unique use matters.

Make a fresh password for each account and keep it safely.

The generator selects characters using the browser's cryptographic random source. It discards byte values that would bias character selection and retries results that do not contain every selected type.

The displayed bits estimate how many valid random strings these settings allow. It describes generated passwords from this tool, rather than passwords people invent. Account protections, exposure and reuse are outside that calculation.
