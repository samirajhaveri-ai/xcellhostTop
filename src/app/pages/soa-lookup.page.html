info

The record that describes a DNS zone

Authority metadata and secondary-server maintenance values.

A zone publishes an SOA at its apex. Its two name fields identify the primary server and responsible party; five numeric fields carry the serial and timers. The RNAME contact uses DNS name notation, so an escaped dot can be part of the mailbox name.

This tool reads an SOA response through your selected public resolver. It can help you review a configuration, but a single cached answer cannot establish agreement across authoritative servers or tell you when every resolver will see a change.

SERIAL

A 32-bit zone version with wraparound comparison rules.

REFRESH / RETRY / EXPIRE

Values used for secondary-server maintenance.

MINIMUM / TTL

Separate values involved in negative-answer caching.

Technical references: SOA fields in RFC 1035 · Negative caching in RFC 2308

checklist

Review a zone in four steps

Start with the DNS zone name, then inspect its fields.

  1. Enter the zone apex

    Use the zone name from your DNS provider, such as example.com.

  2. Choose a public resolver

    Use Google Public DNS or Cloudflare, then run the SOA lookup.

  3. Read the authority and timers

    Check the primary name, contact, serial and the four timing fields.

  4. Compare and retain the snapshot

    Review the original value, share the lookup settings or export a timestamped report.
