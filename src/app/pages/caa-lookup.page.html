info

DNS rules for certificate issuance

A CAA record contains flags, a property tag and its value.

CAA lets a domain publish certificate-issuance instructions. An issuer processes the relevant record set before issuing, including applicable parent and alias lookups. Several properties can be published together, and issuer parameters can add requirements this tool does not interpret.

This page provides a public-resolver snapshot for the exact name entered. Its summaries describe each returned owner name independently. It is useful for configuration review, but does not decide whether a real certificate request is authorized or whether an existing certificate is valid.

ISSUE

Names an issuer for ordinary requests and the wildcard fallback.

ISSUEWILD

Takes precedence for wildcard requests when present in the relevant set.

IODEF

A reporting destination; it does not grant issuance authority.

Technical reference: CAA processing and properties in RFC 8659.
