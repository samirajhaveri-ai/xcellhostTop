school

Crawling rules belong at the origin root

Robots.txt is a public request to cooperating crawlers.

A crawler reads /robots.txt for the relevant scheme, host and port. User-agent lines identify groups; Allow and Disallow describe path patterns. A specific group can override the wildcard fallback, so testing only the * group can miss what a named crawler sees.

HTTP status and cached copies also matter. A file snapshot can explain a rule decision, but it cannot tell you what is in a crawler’s cache or whether a page will be indexed. This tool keeps fetch evidence, local matching and indexing claims separate.

USER-AGENT

A crawler product token or * fallback.

ALLOW / DISALLOW

Case-sensitive path rules with longest-match precedence.

SITEMAP

An absolute URL reference. Its presence does not guarantee indexing.

References: Robots Exclusion Protocol · Google’s robots.txt interpretation.
