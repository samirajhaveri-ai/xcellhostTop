What does a hash tell you?

A compact fingerprint of the bytes you supplied.

A hash function maps input bytes to a fixed-size digest. The same bytes and algorithm give the same result. Changing even one space usually changes the digest, so hashes are useful when comparing downloads, build artifacts and copied data.

Hexadecimal uses two characters per digest byte. Base64 represents the same bytes with a different alphabet and padding. Neither representation encrypts your data, and a matching checksum is meaningful only when you trust the expected value.

EXACT INPUT

Text is UTF-8. Leading spaces, trailing newlines and Unicode differences count.

FIXED OUTPUT

SHA-256 always returns 32 bytes: 64 hex characters or 44 padded Base64 characters.

TRUSTED SOURCE

Get the expected digest from the publisher through a trusted channel.

Algorithm references: SHA-2 standard · SHA-3 standard · BLAKE2 specification.

info

Hashing is not encryption

Digests are one-way fingerprints. Fast hashes are not suitable for storing passwords, and a digest alone does not prove a file's origin.
