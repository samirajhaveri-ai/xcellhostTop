Leadership profile

Samir Jhaveri

Managing Director at XcellHost Cloud Services

College dropout like Bill Gates. With over two decades of experience in the cloud industry, Samir Jhaveri has been at the forefront of digital transformation since 1999. As Managing Director of XcellHost Cloud Services, he has empowered more than 10,000 SMBs and enterprises with cloud, security, digital marketing and AI solutions.

He travels globally, participating in and speaking at cloud conferences. He drives XcellHost’s vision, strategy and growth, helping organisations of every size build simple and robust cloud infrastructure.

Full company bio

Leading Managed Cloud Service Provider since 1999

XcellHost Cloud Services is a leading Managed Cloud Service Provider based in Mumbai, India, providing managed cloud services across the globe. We help customers manage public clouds including AWS, Azure, GCP and Oracle, plus private clouds, across the full cloud management lifecycle: assessment, migration, deployment, management, monitoring, security and DevOps.

Our SaaS-based Cloud Marketplace helps enterprises consume 100+ cloud services and simplify cloud billing, provisioning and partner management, backed by managed 24×7 NOC and SOC services.

SMB bio

Cloud services built for growing businesses

XcellHost Cloud Services is a leading managed cloud service provider since 1999, based in Mumbai, India. Its SMB portfolio includes domains, web hosting, website security, website marketing, business email, Microsoft 365, Tally on Cloud, Backup Cloud, File Cloud, Cloud Desktop and Cloud Conferencing.
