info

How nameservers fit into DNS authority

The difference between a server name, delegation and glue.

An NS record names a DNS server for a zone. A parent delegation helps resolvers find the child zone; the child also publishes its own authoritative data. Comparing those sources is useful when diagnosing a broken delegation.

This page queries your chosen public resolver for NS records, then optionally resolves each returned server name to addresses. It preserves the exact input hostname. Those queries provide a useful snapshot, while a parent/child audit needs direct queries to the relevant authoritative servers.

NS TARGET

A nameserver hostname. Its address is supplied separately.

DELEGATION

The parent zone's referral to servers for a child zone.

GLUE

Address data supplied by a parent to help resolve the delegation.

Technical references: Zone delegation in RFC 1034 · Nameserver targets in RFC 2181
