Five fields describe the schedule

The command follows the time expression in a user crontab.

For example, 30 2 * * MON selects 02:30 on Mondays. A scheduler checks the calendar fields in its configured time zone. The browser preview helps inspect those matches before you add an entry on your server.

*

All values

Select every value allowed in a field.

,

List

0,30 selects two minute values.

-

Range

MON-FRI selects weekdays.

/

Step

*/15 selects 0, 15, 30 and 45 in minutes.

Prepare a scheduled task

Check the expression, execution context and output together.

  1. Start with a preset or custom fields

    Use the expression input to paste an existing five-field schedule, or change fields in the advanced builder.

  2. Inspect the preview

    Choose the intended time zone and review upcoming dates. Refresh the preview start time when needed.

  3. Add your command

    Use server-appropriate paths, choose logging behavior and check percent escaping.

  4. Copy and install on your server

    Review the generated entry, then use your server’s supported user-crontab editing process, such as crontab -e.
