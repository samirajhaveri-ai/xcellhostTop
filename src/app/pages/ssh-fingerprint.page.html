How an SSH fingerprint works

A compact identifier for the public half of a key pair.

An OpenSSH public line contains a key type, a Base64-encoded binary blob and an optional comment. The blob includes the algorithm name and its public parameters. This tool checks that encoding, then hashes the blob. Text comments, authorized_keys options and filenames stay outside the digest.

The preferred algorithm changes which result appears first. It does not create a different key. Compare the complete value using the same algorithm, and obtain the expected fingerprint through a channel you trust.

SHA256

The usual OpenSSH fingerprint display: a prefix and unpadded Base64.

MD5

Colon-separated hex for older systems. It is not collision resistant.

HOST KEY

The server’s public identity key. A user’s login key is a separate credential.

References: ssh-keygen fingerprints · SSH public-key encoding · Ed25519 SSH keys.
