school

Carry bytes through a text format

Base64 changes the representation of data, rather than encrypting it.

Base64 maps groups of bytes onto a 64-character alphabet. It is useful when a system expects text, such as a JSON field or an encoded message body. The conversion can be reversed to recover the original bytes.

Encode

Convert input bytes into Base64 text. Text input first becomes UTF-8.

Decode

Recover the bytes, then display UTF-8 text when those bytes support it.

Padding

Ending = characters fill the final output group when required.

format_list_numbered

Convert in four steps

Choose the direction, source and expected alphabet.

  1. Select encode or decode

    Encode starts from text or file bytes. Decode starts from Base64 text.

  2. Choose the source and variant

    Paste text or select a local file. Match standard Base64 or Base64url to the destination.

  3. Convert and inspect

    Review output sizes and the text or hex preview. Validation errors identify malformed input.

  4. Copy, download or reverse

    Copy the full result, save it, or move compatible output into the opposite conversion input.
