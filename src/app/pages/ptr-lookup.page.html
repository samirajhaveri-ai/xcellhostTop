info

Looking up a name from an address

Reverse DNS uses a separate part of the DNS namespace.

An ordinary address lookup starts with a hostname. A PTR lookup starts with an IP address and asks its reverse zone for names. IPv4 uses reversed decimal octets under in-addr.arpa; IPv6 uses reversed hexadecimal digits under ip6.arpa.

This page can query each returned hostname in the corresponding address family and compare the result with the original IP. The check is useful when reviewing server configuration, but it is not a network connection test or a guarantee that mail will be accepted.

PTR TARGET

A hostname returned by a reverse DNS query.

REVERSE ZONE

The DNS namespace used to look up an address, normally managed through the block provider.

FCrDNS

Forward-confirmed reverse DNS: the hostname resolves back to the original IP.

Technical references: IPv4 reverse DNS in RFC 1035 · IPv6 reverse DNS in RFC 3596.
