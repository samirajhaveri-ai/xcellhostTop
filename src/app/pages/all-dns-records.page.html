info

The records behind a domain

Different services depend on different parts of DNS.

A website can resolve correctly while email is misrouted. Checking several types together helps you compare the addresses, aliases and mail policies that applications receive for the same name.

This check sends separate queries for each supported type. It does not rely on an ANY query, whose response can be limited by a DNS server. Results come from your selected public resolver and can reflect its cache.

A · AAAA · CNAME

Find addresses and hostname aliases used to locate services.

MX · TXT · SPF · DMARC

Review mail routing, verification strings and published email policies.

NS · SOA · CAA

Inspect nameservers, zone metadata and certificate issuance rules.

checklist

From domain to DNS snapshot

A practical way to review a change or troubleshoot a service.

  1. Start with a hostname

    Enter your domain, or paste a URL. Use the exact subdomain if that is what you need to inspect.

  2. Select a resolver and run

    Open Advanced settings to choose a provider, then start all nine queries together.

  3. Read the results by type

    Use the filters to inspect values and TTLs. Empty groups are shown separately from failed requests.

  4. Compare and keep a report

    Review the answers against your DNS provider’s configuration. Export a snapshot or share a link for another lookup.
