Understand the answers

How DNS connects a hostname to its destination.

DNS records tell applications where to find a domain’s services. An A record supplies an IPv4 address; other record types describe IPv6 addresses, email routing, aliases or domain verification.

This tool asks the public resolver you select. It displays that resolver’s answer at the time of the query, so a recent change may still be waiting for an older cached response to expire.

A / AAAA

Address records for IPv4 and IPv6 connections.

TTL

The number of seconds an answer can remain cached.

CNAME

An alias that points a hostname to another DNS name.
