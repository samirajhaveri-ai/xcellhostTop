school

Percent escapes carry byte values

The same character can be data in one place and syntax in another.

A percent escape uses % followed by two hexadecimal digits. A space becomes %20; non-ASCII text first becomes UTF-8 byte sequences. Choose a mode according to whether the input is one value or an already assembled URI.

Component

Escape separators that belong to the data, such as an ampersand inside a search value.

Whole URI

Keep the scheme, path, query and fragment separators in their structural roles.

One pass

Percent signs are data too. An existing escape can become double-encoded on a second encode.

Convert in four steps

Pick the direction, mode and size of the operation.

  1. Paste text or a URI

    Keep the exact value you need to convert. Spaces are preserved, and batch mode uses one entry per line.

  2. Choose encode or decode

    Use component mode for values, or whole-URI mode to preserve structural separators.

  3. Review results and errors

    Inspect each batch row, use pagination for longer lists and correct malformed escapes where needed.

  4. Copy or export

    Copy a single result or successful outputs. Use JSON when line numbers, empty values or failures matter.
