Six bytes. A few bits that matter.

Understand the notation before using a generated value.

A 48-bit MAC address is commonly written as six hexadecimal byte pairs. Its first octet contains the group and local-administration bits. A vendor prefix can describe an assigned address range, but a generated prefix match does not identify a physical device or establish an allocation.

Unicast

The group bit is zero. This is the individual-address form produced by both modes here.

Local administration

The local bit is one. Random mode uses this space for software-assigned addresses.

Prefix

Vendor-style samples preserve three fixed bytes and randomize the permitted suffix.

Generate an address list in four steps

Choose, format, generate and reuse the output.

  1. Choose an address type

    Start with local random unicast addresses, or select vendor-style samples for lab data.

  2. Set the notation

    Pick colons, hyphens, dots or no separator. Choose uppercase or lowercase hexadecimal.

  3. Generate your batch

    Create between 1 and 200 addresses. Duplicate values are rejected within the current batch.

  4. Copy or download

    Copy individual addresses or the full list. Check your platform’s requirements and available address pool before assignment.
