Overview

Microsoft runs the Microsoft 365 service. Your mail, files, sites and chats are yours to protect — Microsoft's own terms recommend you back them up. Recycle bins and retention policies help with small mistakes, but they sit inside the same tenant, expire on a timer and weren't built to roll a whole user back to before a ransomware attack. XcellHost Microsoft 365 Backup copies Exchange Online, OneDrive, SharePoint and Teams automatically, several times a day, into immutable, encrypted storage outside your tenant. Restore a single email, a folder, a site or an entire user to any point in time — to the original location, to a new one, or as a download — without overwriting what's still intact.

Do you need to back up Microsoft 365?

Yes. Under Microsoft's shared responsibility model, Microsoft keeps the Microsoft 365 service available, but the data inside it — mail, files, sites and chats — is the customer's responsibility, and the Microsoft Services Agreement recommends customers regularly back up their content. Native recycle bins and retention settings keep deleted items only for limited windows that depend on the workload and licence, and they live in the same tenant as the data they protect. A third-party Microsoft 365 backup keeps independent, encrypted, immutable copies with retention you set, and restores individual items or whole users to any point in time.

    Frequently Asked Questions

    Do you need to back up Microsoft 365?
    Yes. Under Microsoft's shared responsibility model, Microsoft keeps the Microsoft 365 service available, but the data inside it — mail, files, sites and chats — is the customer's responsibility, and the Microsoft Services Agreement recommends customers regularly back up their content. Native recycle bins and retention settings keep deleted items only for limited windows that depend on the workload and licence, and they live in the same tenant as the data they protect. A third-party Microsoft 365 backup keeps independent, encrypted, immutable copies with retention you set, and restores individual items or whole users to any point in time.
    What is SaaS backup?
    SaaS backup is an automated process that copies data from cloud applications like Microsoft 365 to separate, secure storage. It protects against deletion, corruption, ransomware and account compromise, and makes point-in-time recovery possible.
    What is SaaS recovery?
    SaaS recovery is restoring data from those backups to its original location or a new one — a single email, a file, a site, a channel or a whole user — back to the state it was in at a chosen point in time.
    What's the difference between backup and SaaS backup?
    Traditional backup protects servers, databases and files on infrastructure you manage. SaaS backup protects data that lives in cloud applications like Microsoft 365, where you don't control the underlying infrastructure but are still responsible for the data.
    How does SaaS backup protect my data?
    It keeps independent, encrypted copies outside the application. If data is deleted, overwritten, encrypted by ransomware or lost to an account compromise, you restore it from a copy the incident couldn't reach.
    What types of data does Microsoft 365 backup protect?
    Email, calendars and contacts in Exchange Online; files and folders in OneDrive; sites, libraries, lists and permissions in SharePoint; and teams, channels, conversations and files in Microsoft Teams.
    Which Microsoft 365 applications are supported?
    Exchange Online, OneDrive, SharePoint and Microsoft Teams. For the identity layer — users, groups, roles and Conditional Access — pair it with XcellHost Entra ID Backup.
    How often is data backed up?
    Automatically, several times a day by default, on a schedule we agree with you — from hourly to daily, with weekly and monthly points kept for longer-term retention.
    How easy is it to restore?
    Search, pick a point in time, select the items and choose where they go. Restores don't overwrite intact data unless you ask them to, and our team will run them for you on request.
    How long is backup data retained?
    As long as your policy requires — days, years or indefinitely — including previous versions and deleted items, well beyond native recycle-bin windows.
    Doesn't Microsoft already back up Microsoft 365?
    Microsoft replicates data to keep the service available and offers recycle bins and retention settings, but it doesn't give you an independent, point-in-time backup you control. Under the shared responsibility model, protecting the data is the customer's job.
    Where is our backup data stored?
    In encrypted, immutable storage outside your Microsoft 365 tenant. We'll confirm the storage location at onboarding so you can answer data-residency and DPDP Act questions.
