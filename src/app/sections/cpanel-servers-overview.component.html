What is a cPanel server?

A cPanel server is a VPS or dedicated server with cPanel & WHM installed — the industry-standard control panel for hosting websites, email, databases and DNS. WHM lets you create and manage separate cPanel accounts for each site or customer. XcellHost delivers cPanel-optimised servers with the licence pre-installed, so you get the full performance of the server for your sites, billed in INR.
