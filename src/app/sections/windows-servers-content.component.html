Windows Server licensing explained

Per-core model

  • Microsoft licenses Windows Server per physical core
  • Minimum 8 cores per CPU and 16 cores per server
  • XcellHost includes compliant per-core licences (SPLA)

Standard edition

  • 2 virtual machines per licence
  • 1 Hyper-V host
  • Best for low-to-mid VM density

Datacenter edition

  • Unlimited VMs and Hyper-V containers
  • Storage Spaces Direct, Shielded VMs, SDN, Storage Replica
  • Best for high-density virtualisation

CALs, RDS & SQL

  • User or device CALs where required
  • RDS CALs for centralised desktops
  • SQL Server licensed separately — per core or Server + CAL
