Overview — What is XcellHost Server Monitoring?

XcellHost Server Monitoring, powered by TSplus, gives you a single, real-time view of the health of every server and website you run. Watch CPU, memory and disk usage, Windows services, processes and connected users from one clean dashboard.

When a disk fills up, a service stops, or a site becomes slow or unavailable, you receive an instant alert. XcellHost sets it up, tunes thresholds to your environment and can watch it for you 24×7, with local support and a GST invoice.
