What is managed MongoDB?

Managed MongoDB is a hosted MongoDB database where XcellHost handles provisioning, replica sets, backups, monitoring, patching and failover, so your team focuses on the application. Choose a standalone node for development or a three-node replica set for production, with point-in-time recovery, in Indian data centres.

Development

Production default

Replica set

Best for: Production workloads needing availability and automatic failover

  • Primary + two secondaries
  • Automatic election on failure
  • Read preference for secondaries
  • Majority write concern
