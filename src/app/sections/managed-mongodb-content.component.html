What is managed MongoDB?

Managed MongoDB is a hosted MongoDB database where XcellHost handles provisioning, replica sets, backups, monitoring, patching and failover, so your team focuses on the application. Choose a standalone node for development or a three-node replica set for production, with point-in-time recovery, in Indian data centres.

Frequently asked question

What is managed MongoDB?
Managed MongoDB is a hosted MongoDB database where XcellHost handles provisioning, replica sets, backups, monitoring, patching and failover, so your team focuses on the application. Choose a standalone node for development or a three-node replica set for production, with point-in-time recovery, in Indian data centres.
Which MongoDB versions do you support?
MongoDB 8.0 and 7.0, with 6.0 available as an upgrade path. We plan major-version upgrades with you.
Is this MongoDB Atlas?
No. XcellHost runs MongoDB Community Edition on its own infrastructure in India, fully managed by our engineers.
What deployment options are available?
Standalone instances for development and non-critical workloads, and three-node replica sets for production — with scale-out guidance as you grow.
How does failover work?
A replica set has one primary and two secondaries. If the primary fails, the secondaries elect a new primary in seconds and drivers reconnect automatically.
Do you support backups and point-in-time recovery?
Yes. Scheduled backups and point-in-time recovery are included; restores go to a new cluster so you can verify before switching.
Do you support sharding?
For workloads that outgrow one replica set we design a sharded cluster — shard keys, config servers and routers — and quote it per project.
How is pricing calculated?
Each plan has a fixed hourly and monthly compute price per node; a replica set runs three nodes, storage is billed per GB-month and backups are included. All in INR with GST.
Can I migrate from Atlas or self-managed MongoDB?
Yes. We assess the source, back up first, sync the data and validate indexes and connectivity before cutover.
How is access secured?
TLS encryption, encryption at rest, SCRAM authentication, role-based access, private networking and IP allow-lists.
Do you offer a free consultation?
Yes. We size and design your deployment for free before you commit.
