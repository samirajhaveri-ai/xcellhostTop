What is Imunify360?

Imunify360 is a complete security suite for Linux web servers. It layers a network firewall, WebShield, web application firewall, intrusion prevention, Proactive Defence, a malware scanner with automatic cleanup, KernelCare and HardenedPHP to detect and eliminate threats automatically.
