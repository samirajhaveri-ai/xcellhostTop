01The short version#

Acronis licenses protection per workload. A workload is any protected server, virtual machine, PC, mobile device, Microsoft 365 or Google Workspace seat, or website. There are two ways to buy. Service providers like XcellHost buy monthly and pay for what was used. Companies running Acronis themselves buy annual subscriptions. Most Indian businesses buy through a provider, so this guide starts with that route.

The name changed on 14 October 2026

Acronis Cyber Protect Cloud is now Acronis Cyber Platform. Acronis Cyber Protect, the corporate product, now carries the same name. Older quotes, consoles and licence keys may still show the old names.

Two licensing models, one per customer

Solution-based sells one bundle per workload. Service-based charges per workload or per GB, then adds services. Each customer tenant uses only one of the two.

Basic protection costs nothing extra

Standard features such as vulnerability assessment and device control are free. Additional services start billing only once you switch them on in a protection plan.

Storage is a separate decision

You can store backups in Acronis's cloud (it has had a Mumbai data centre since 2021), with your provider, in your own Azure or S3 bucket, on local disks, or a mix of these. Solution-based bundles include a pooled storage allowance.

XcellHost bills monthly in INR

Our listed prices start at ₹349 per workstation and ₹1,499 per server a month on the Acronis platform. Direct Backup to your own bucket starts at ₹199 per workload. All are indicative and exclude 18% GST.

Perpetual licences are gone

Acronis stopped selling new perpetual licences on 1 January 2022 in every country except Japan. If you renew an old perpetual setup today, you are moving to a subscription.

Tip

Count your workloads before you compare prices. Make a list of servers, VMs, PCs, mailboxes and sites, and note how much data each one holds. Tools 1 to 4 in this guide use exactly those numbers.

04Licensing models on Cyber Platform#

The provider sets the licensing mode for each customer tenant. Acronis's documentation is explicit: a partner tenant can enable every mode, but a customer tenant can use only one. You can change your model later, but you cannot mix two models in one tenant.

Solution-based: one bundle per workload

One SKU per workload covers a set of capabilities, and storage is pooled across the customer. Acronis names three packages for servers, VMs and workstations, and three for Microsoft 365:

Managed Detection and Response (MDR) and Security Awareness Training (SAT) are billed separately and can be added to any package. Storage used beyond the pool is billed automatically, except for Microsoft 365, which has no overage.

Service-based: pay per workload or per GB, then add services

Service-based licensing bills each service separately. The base protection is billed in one of two units:

  • Per workload: a fixed monthly price for each protected workload. Local storage and storage hosted by the provider carry no separate Acronis charge. Fees for Acronis cloud storage apply.
  • Per gigabyte: billing follows the total protected data across cloud, provider and local storage, with no limit on the number of workloads.

Both units have the same feature set. Additional services such as Detection and Response, Disaster Recovery and Email Security are licensed and billed automatically when a protection plan uses them. Acronis's documentation says they cannot be changed by hand.

Tip

Acronis says a customer's model "can be changed at any time" at customer level. Try one model for a few months, look at the invoice, then decide. Ask XcellHost to show you the usage report before you switch.

05Per workload vs per GB: which is cheaper?#

The answer depends on how much data sits behind each workload. With per-workload pricing, a lightly used PC costs the same as a busy file server. With per-GB pricing, many small endpoints cost little, but one large database server can cost a lot. The break-even point is the per-workload rate divided by the per-GB rate.

    Corporate licensing rules worth knowing

    • One licence per device. Each workstation, server or physical host needs a licence. Each node in a cluster must be licensed.
    • Virtual Host licences cover one hypervisor host and an unlimited number of VMs on it.
    • Microsoft 365, Google Workspace and Email Archiving are sold in packs of five seats on 1, 3 or 5-year terms, with unlimited cloud storage.
    • Cloud deployment (the management server in an Acronis data centre) is available only with subscription licences.
    • No new perpetual licences since 1 January 2022, except in Japan. Existing perpetual holders get free upgrades within one major version.
    • Not transferable. A licence cannot be moved to another person. It can move to a replacement machine only when the original is retired.
    • Keys expire. Subscription serial keys are time-stamped and stop working when the paid term ends.
    Watch out

    If your backups rely on an expired key, they stop at the end of the term. Note the renewal date wherever your finance team will see it, and renew before the expiry date. Renewals bought before expiry extend from the current end date, so you lose nothing by renewing early.

    13The Acronis Anti-Ransomware Recovery Warranty#

    Acronis offers a recovery warranty on qualifying recovery points. It needs no separate purchase and applies automatically to customers who meet the prerequisites. The covered event does not have to be ransomware.

    Prerequisites (per Acronis)

    • Endpoint data is backed up to Acronis Cloud Storage
    • Two-factor authentication is enabled
    • Recovery points are protected by immutable storage in Compliance mode
    • Recovery points are validated by an approved method (checksum, screenshot or heartbeat)

    Limits

    • Reimburses qualifying recovery costs up to the lesser of US$1 million or the fees paid to Acronis for the relevant services in the previous 12 months
    • Not cyber insurance, and it does not replace it
    • Eligibility, covered events and claims are governed by Acronis's final Warranty Policy and your agreement
    Watch out

    Backups kept only on XcellHost-hosted storage, your own S3 bucket or a local NAS do not meet the "backed up to Acronis Cloud Storage" prerequisite. If you want the warranty, add an Acronis cloud copy. See our warranty-readiness page.

    17Mistakes to avoid#

    1. Comparing "per server" prices from two different products. Platform Essentials and Direct Backup differ in features and in where the storage sits.
    2. Forgetting storage. Per-workload pricing excludes Acronis cloud storage fees. Size it with Tool 4.
    3. Switching on services in a shared plan. Additional services bill per workload as soon as they are used.
    4. Expecting public cloud buckets to hold M365 backups. They can't. Choose another destination for mailboxes.
    5. Assuming the warranty covers every backup. It needs Acronis Cloud Storage, 2FA, Compliance-mode immutability and validation.
    6. Licensing only one node of a cluster. Every node needs a licence.
    7. Letting a corporate key expire. Backups stop when the subscription term ends.
    8. Leaving orphaned backups. Data from deleted workloads is billed as standard storage.
    9. Using "India region" loosely. Get the storage, console and log locations in writing.
    10. Buying for today's names. Quotes may say Cyber Protect Cloud or Cyber Platform. Match line items, not labels.

    19Glossary#

    Additional service
    A billable capability on top of standard protection, such as Detection and Response, DR, Email Security, RMM, DLP or GenAI Protection. Formerly called an "Advanced pack".
    Advanced Backup
    Application-aware backup, cluster support, off-host processing and one-click restore. Included in Ultimate.
    Agentless backup
    VM backup through the hypervisor without installing an agent in each guest, where the hypervisor allows it (e.g. Proxmox, Nutanix AHV).
    Commitment tier
    The minimum monthly spend a service provider agrees with Acronis. Higher tiers bring volume discounts.
    Compliance mode
    An immutable-storage setting in which recovery points cannot be deleted before their retention ends. Required for the warranty.
    Customer tenant
    Your organisation's space in the provider's multi-tenant console. One licensing model applies per customer tenant.
    Cyber Console
    Acronis's new AI-native interface for Cyber Platform, in early access in October 2026.
    Cyber Frame
    Acronis's hyper-converged IaaS platform for providers. Cloud is billed on consumed resources, Local per physical CPU core.
    Cyber Platform
    The name since 14 Oct 2026 for Acronis Cyber Protect Cloud (service providers) and Acronis Cyber Protect (corporate).
    #CyberFit Score
    A standard (free) security posture score per workload.
    DeployPilot
    Software deployment across client estates, part of Acronis RMM.
    Direct backup to public cloud
    Backups written straight to Microsoft Azure, Amazon S3 or S3-compatible storage. Not available for M365 or Google Workspace backups.
    EDR / XDR / MDR
    Endpoint, extended, and managed detection and response. Part of the Detection and Response service. MDR is billed separately.
    Geo-replication
    A second copy of cloud backups in another data centre, billed separately.
    Hybrid backup
    A local copy for fast restores plus a cloud copy for disasters.
    Immutable storage
    Backups that cannot be changed or deleted for a set time, which protects against ransomware and rogue admins.
    Offering item
    A licensable line in the Acronis console. A workload cannot have more than one.
    Orphaned backup
    Backup data left after a workload is removed. Billed as standard storage under solution-based licensing.
    Per-GB licensing
    Service-based billing on total protected data across cloud, provider and local storage, with unlimited workloads.
    Per-workload licensing
    Service-based billing at a fixed monthly price per protected workload.
    Ramp-up period
    The one month Acronis gives new partners to get started.
    Solution-based licensing
    One bundle per workload (Backup + DR, Security + RMM, Ultimate) with pooled storage.
    Virtual Host licence
    A corporate licence that covers one hypervisor host and unlimited VMs on it.
    Workload
    Any protected unit: server, VM, workstation, mobile, M365 or Google seat, website, web hosting server.

    No terms match.
