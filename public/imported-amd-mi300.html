Overview · AMD Instinct MI300X

Large models need memory first. MI300X starts with 192 GB.

Most LLM projects are limited by GPU memory before they are limited by compute. When the weights and the KV cache fit on fewer GPUs, you split the model less, move less data between cards and serve more users per node.

The AMD Instinct MI300X is AMD's data-centre accelerator for generative AI and HPC. Per AMD, each GPU carries 192 GB of HBM3 at up to 5.3 TB/s peak bandwidth, with 304 compute units on the CDNA 3 architecture. Eight of them sit on one baseboard, linked by AMD Infinity Fabric, for 1.5 TB of GPU memory in a single node.

That much memory changes the maths for large models. A 70-billion-parameter model at FP16 needs about 140 GB for its weights. That fits on one MI300X, where an 80 GB card needs two. Fewer GPUs per model means simpler serving and more headroom for long prompts.

Features & benefits

Five reasons teams choose MI300X. All from AMD's published design.

Memory, bandwidth, chiplets, open software and multi-GPU scaling. Each card shows what the feature does for your workload.

01 / 05
01

192 GB HBM3 per GPU

About 2.4 times the 80 GB of an NVIDIA H100. Larger models and longer prompts fit on one card, with less splitting across GPUs.

  • 70B at FP16 fits on one GPU
  • Room left for KV cache
02

5.3 TB/s memory bandwidth

Token generation is mostly a memory read. Higher bandwidth keeps 304 compute units and 1,216 matrix cores fed during inference.

  • Faster token generation
  • 304 CUs · 1,216 matrix cores
03

Chiplet architecture

Eight compute dies are stacked on four I/O dies and share 256 MB of AMD Infinity Cache. The design packs more compute and memory into one package.

  • 8 compute dies · 4 I/O dies
  • 256 MB Infinity Cache
04

Open software with ROCm

AMD's open-source ROCm platform runs PyTorch, TensorFlow, JAX and ONNX Runtime, plus serving engines such as vLLM. Many models run with little or no code change.

  • Open-source drivers & libraries
  • HIP for porting CUDA code
05

Multi-GPU scaling

Each GPU has seven Infinity Fabric links at 128 GB/s, one to each other GPU on the baseboard. An 8-GPU node pools 1.5 TB of HBM3 for one large job.

  • 7 × 128 GB/s links per GPU
  • 1.5 TB per 8-GPU node

Specifications per AMD. H100 memory per NVIDIA. Software compatibility varies by model and version; we test your stack before go-live.
