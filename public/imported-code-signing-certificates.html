Overview

Prove the code is yours — and that nobody changed it after the build.

A DigiCert code signing certificate puts a verified digital signature on installers, executables, libraries, drivers and scripts. Windows, app stores and operating-system vendors check that signature before they let your software run quietly: it names your company as the publisher, and it breaks the moment a single byte of the file is altered — so tampered or repackaged copies stand out instead of passing as yours.

You choose two things. Validation: OV for most applications, or EV when you sign Windows kernel-mode drivers and need Microsoft's attestation route. Key storage: DigiCert KeyLocker keeps the key in a cloud HSM so developers and CI pipelines anywhere can sign without a token; or take a DigiCert eToken, your own qualified token, or your own HSM. XcellHost handles the MCA, GST or Udyam paperwork, sets up signing and bills in rupees.

01

MFA & signing authorisation

A signature only happens when the key's hardware — token, HSM or KeyLocker — and a second factor agree. No copied file can sign in your name.

  • Token PIN, client certificate or MFA
  • Per-user signing rights in KeyLocker

DigiCert checks your organisation — or you, as an individual developer — before issuing, so the publisher name users see is one somebody actually verified.

DigiCert KeyLocker

The signing key lives in a cloud HSM. No token to ship, lose or plug in.

KeyLocker keeps your code signing key inside a FIPS 140-2 Level 2 HSM run by DigiCert. Developers and build agents send a file's digest, prove who they are, and get the signature back — from any city, any machine, any pipeline.

Cloud-hosted FIPS 140-2 Level 2 keys

Generated and kept in DigiCert's HSM, non-exportable — it meets the hardware rule for code signing keys without any device on your desk.

No token to ship or lose

Nothing to courier, nothing left in a laptop bag, and no single build machine your release depends on.

Sign from anywhere

Windows through Microsoft KSP, Linux through PKCS#11, macOS through CryptoTokenKit — the key appears as if it were local.

CI/CD pipeline signing

Jenkins, GitHub Actions, GitLab, Azure DevOps and CircleCI sign as a pipeline step, using credentials stored as secrets.

MFA and audit logs

Signing needs an API key plus a client certificate, with MFA for people; every signature is logged with who, what and when.

Built for distributed teams

It is a certificate that lets you attach a digital signature to software you publish. Anyone running the file can check who published it — your name, verified by DigiCert — and that the file hasn't been changed since it was signed. It does not encrypt or hide your code.

      
Unsigned or altered files are the easiest way to slip malware onto a machine, so Windows, browsers and store operators treat them with suspicion — warnings, blocks or rejections. A valid signature from a verified publisher removes "Unknown Publisher" and shows the file arrived intact.

      
OV verifies a registered organisation or an individual developer and suits most apps, installers, scripts and macros. EV adds stricter checks on the organisation, is available to registered entities only, and is what Microsoft's Hardware Dev Center requires to submit kernel-mode drivers for attestation signing.

      
An eToken is a USB device that holds the key — it signs on whichever single machine it's plugged into. KeyLocker keeps the key in a DigiCert-run cloud HSM (FIPS 140-2 Level 2) and lets authorised people and CI pipelines sign remotely, with MFA and an audit log. Nothing ships, and nothing can be lost in transit.

      
Yes. Since June 2023 industry rules require code signing keys to be generated and kept on certified hardware — FIPS 140-2 Level 2 or Common Criteria EAL4+. KeyLocker, a DigiCert eToken, a qualified token you own, or your own HSM all meet that; a downloadable .pfx file does not.

      
Usually MCA master data with your CIN (or GSTIN, Udyam or Shop & Establishment for other entities), proof of address, a verifiable phone number, and photo ID for the authorised contact.
