Overview

Flexible, scalable portfolio management — on infrastructure you choose.

Project Server Subscription Edition is Microsoft's on-premises platform for project portfolio management and everyday project work.

Project Server SE runs as a service application inside SharePoint Server Subscription Edition, with its data in SQL Server. Teams work in Project Web App from a browser or in Project Professional on the desktop: proposals become projects, projects compete for budget and people, schedules and timesheets roll up into portfolio views, and everything is reportable through OData into Power BI.

Because it runs on servers you control, it suits organisations that need data residency, custom governance or long-term stability. XcellHost licenses the stack through Microsoft programmes, builds the farm on our India cloud or your premises, migrates your projects and supports it 24×7 from Mumbai — on one GST invoice in rupees.

Portfolio lifecycle

Twenty-four ideas, six stages — scroll from proposal to portfolio report.

The same twenty-four proposals move through demand intake, selection, scheduling, resourcing, time tracking and reporting in Project Server SE.

  1. 01Demand managementCapture every request

    Ideas and requests arrive through one intake form in Project Web App. Enterprise project types decide which questions are asked and which stage-gates each request must pass.

    Proposals · stage-gates
  2. 02Portfolio analyticsSelect what to fund

    Score proposals against business drivers, set cost and resource constraints, and let portfolio analysis show the set that delivers most strategic value for the money.

    Drivers · efficient frontier
  3. 03Schedule managementPlan the work

    Approved projects get schedules in Project Professional or the browser: tasks, dependencies, baselines and milestones, with changes tracked against the plan.

    Gantt · baselines
  4. 04Resource managementBalance the people

    One enterprise resource pool shows surpluses and shortfalls across the planning horizon, so managers can move work or people before teams burn out.

    Capacity · heatmap
  5. 05Time & task managementTrack actual effort

    Team members update tasks and submit timesheets in one place; approved hours flow back into schedules and cost so actuals stay honest.

    Timesheets · status
  6. 06Reporting & BIDecide with data

    Issues, risks, cost and progress roll up into portfolio dashboards. The OData feed connects Power BI so leadership sees one version of the truth.

    Power BI · OData
