    Overview

    The server, the panel and the licence — bought once, run by one team.

    A Plesk Server is an XcellCloud VPS or dedicated machine that arrives with Plesk Obsidian installed, licensed and hardened, so you start by adding websites instead of building a server.

    Plesk is a web hosting control panel from WebPros. From one browser screen it runs websites, WordPress, email, DNS, databases, SSL certificates and backups on Linux or Windows. Buying it on your own server usually means three suppliers: one for the server, one for the licence and someone to install and patch both. XcellHost puts the three together on one plan and one GST invoice.

    Every Plesk Server runs on pure NVMe in our Mumbai data centre, on the same platform as XcellCloud VPS. We choose the Plesk edition that fits your domain count, keep the licence renewed, apply OS and Plesk updates, watch the server 24×7 from our NOC and help you with sites and mail when you ask. Engineers answer in Hindi or English.

    How the licence works on a Plesk Server

    One licence per server

    Per WebPros, a VPS licence runs only on a virtual server; a dedicated licence runs on dedicated or virtual hardware with the same features. We supply the right type for your plan.

    Change edition any time

    Plesk editions can be switched without reinstalling. Ask us and the new edition applies from your next billing cycle*.

    Renewed with your server

    The licence key is bound to your server and renewed by XcellHost on the same invoice — no separate WebPros account to manage.

    Extensions on request

    Imunify360, WP Toolkit Deluxe and other paid extensions are added as monthly add-ons. Free extensions such as Docker and Git are installed on request.

      What you can do in Plesk

      Sites, WordPress, mail and code — from one browser tab.

      Feature names are WebPros'; availability depends on edition and installed extensions. We switch on what you need.

      WP Toolkit: every WordPress site on one dashboard

      Per WebPros, WP Toolkit installs WordPress end to end — files, database, database user and admin — and manages many sites together.

      • Update core, plugins and themes across many sites at once
      • Clone to staging, test, then sync back (Web Pro & Web Host)
      • Security check with one-click hardening
      • Smart Updates test an update on a copy first (Deluxe add-on)
      • WP-CLI, maintenance mode, debug and indexing controls

      Websites and subscriptions

      Add a domain, and Plesk creates the web space, DNS zone, mail domain and SSL in one go.

      • nginx in front of Apache on Linux; IIS on Windows
      • Multiple PHP versions side by side, chosen per site
      • Service plans, subscriptions and customer logins
      • Sitejet Builder for simple sites without code
      • MySQL / MariaDB; MSSQL on Windows

      Room for developers

      Plesk is not only for WordPress. Deploy apps the way your team already works.

      • Git deployment from your repository
      • Docker containers managed from the panel
      • Node.js, PHP and Python apps
      • SSH access and scheduled tasks (cron)
      • Full root on your server — it's yours

      Mail and DNS on the same server

      Mailboxes, forwarders and spam filtering live next to the website they belong to.

      • Mailboxes, aliases, forwarders and webmail
      • SPF, DKIM and DMARC records per domain
      • DNS zone editor, with DNSSEC available
      • Spam filtering; Plesk Email Security as an add-on*
      • SSL on webmail and mail services

      Backups at two levels

      We snapshot the whole server; Plesk backs up each subscription so a single site can be restored on its own.

      • Weekly server snapshot included; daily as an add-on
      • Per-site restore from the Plesk Backup Manager
      • Off-server copies to object storage on request
      • WP Toolkit restore points before updates
      • Acronis cloud backup for critical data*
