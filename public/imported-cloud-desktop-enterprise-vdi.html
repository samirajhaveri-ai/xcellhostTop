    Overview

    Enterprise VDI without building a VDI team.

    Virtual desktop infrastructure puts every user's Windows desktop on servers in a data centre and streams only pixels to the device. It is how banks, hospitals, BPOs, engineering firms and multi-site manufacturers keep data off laptops, onboard staff in minutes and patch one image instead of 500 PCs. It is also hard to run well: brokers, gateways, profile storage, image pipelines, capacity planning and the 9 AM login storm all need daily care.

    Cloud Desktop Enterprise (VDI) is XcellHost's managed VDI service. We size it, build it in our Mumbai cloud (or in your data centre), run the platform you choose — Citrix, Omnissa Horizon (formerly VMware Horizon), Microsoft Azure Virtual Desktop or Accops — and operate it 24×7: images, patching, autoscaling, monitoring, security policies and user support. You get per-user pricing in rupees and one team accountable for the whole stack.

          None by default. Citrix and Omnissa Horizon suit large, policy-heavy or graphics-heavy estates and teams that already know them; Azure Virtual Desktop suits organisations with eligible Microsoft 365 or Windows Enterprise licences that want Windows 11 multi-session on Azure; Accops suits buyers who prefer an Indian vendor and simpler licensing. The platform chooser above gives a first view and the PoC confirms it.

          No. Per Microsoft, Windows Enterprise multi-session is licensed for production only inside the Azure Virtual Desktop service. In our Mumbai cloud, shared (pooled) desktops run on Windows Server session hosts, and personal desktops run Windows 11. If you need Windows 11 multi-session, we run Azure Virtual Desktop for you in an Azure India region instead.

          It depends on the design, so treat this as a guide — subject to Microsoft licensing, and we'll advise. Windows Server session hosts need Remote Desktop Services CALs (with Software Assurance where required) or RDS subscription licences. Personal Windows 11 desktops need virtualisation rights such as Windows Enterprise E3/E5 or Windows VDA, and where they are hosted affects which licences qualify. Azure Virtual Desktop users need an eligible licence such as Microsoft 365 E3/E5/F3/Business Premium or Windows Enterprise E3/E5.

          Usually, yes — subject to the vendor's terms for hosted use. We check your entitlements during the assessment. If you'd rather not manage licences, we can quote platform licences bundled into the per-user price.

          Pooled (non-persistent) desktops reset to the golden image after sign-out and keep each user's profile in an FSLogix container — lowest cost and easiest to patch, ideal for task and knowledge workers. Personal (persistent) desktops keep user-installed apps and changes, better for developers, power users and GPU designers. Most estates mix both.

          Autoscaling rules start extra session hosts before the morning peak and drain them in the evening, and profile containers keep sign-ins quick. We tune the schedule from real sign-in data after go-live and report logon times monthly.

          We update the golden image, test it on a test ring, release it to a pilot ring and then to everyone in an agreed window. The previous image is kept, so rollback is one step. Personal desktops are patched in place on a schedule.

          Office and ERP work typically uses a few hundred kbps per user; video calls and multi-monitor setups need more, and 3D work needs the most. We measure your offices during the assessment and recommend internet, VPN or MPLS links per site.
