        08 — How licensing works

        One licence per server, tied to it — and movable when you move.

        The rules below follow WebPros' published licensing terms; XcellHost handles the paperwork on your behalf.

        Licence ordered on an INR invoice…
        1. A
          Per server, not per site

          One licence covers one Plesk server; the edition sets how many domains it can host (10, 30 or unlimited).

        2. B
          VPS vs dedicated

          VPS licences run only on virtual servers. Dedicated licences run on physical or virtual servers. Same features.

        3. C
          Bound on activation

          When the key is activated, the licence is tied to that server's IP. If you rebuild, change IP or move servers, we re-bind it.

        4. D
          Upgrade or downgrade any time

          No contract. Move between editions as your domain count changes; we adjust the next invoice.

        5. E
          Subscription, auto-renewing

          Plesk has no perpetual licences. Monthly or annual terms renew until you cancel with us.

        11 — Migration help

        Moving from cPanel or an old server? We bring the sites, mail and databases.

        Plesk Migrator moves subscriptions, websites, mail and databases from cPanel, DirectAdmin and older Plesk servers, among others. We plan it, run it and check every site afterwards.

        1. 01Inventory

          Domains, mailboxes, databases, PHP versions, cron jobs and DNS on the old server.

        2. 02Copy

          Plesk Migrator pulls files, mail and databases to the new server while the old one keeps serving.

        3. 03Test

          We preview each site on the new server and fix PHP or permission differences.

        4. 04Cut over

          DNS switched in a window you choose, with a final mail and database sync.

        5. 05Settle

          SSL re-issued, backups scheduled, old server kept until you sign off.
