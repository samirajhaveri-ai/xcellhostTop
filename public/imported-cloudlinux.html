    Overview

    A shared server is a building of tenants. CloudLinux gives every tenant a locked flat.

    On an ordinary Linux hosting server, every account draws from the same CPU, memory, disk and database. One WordPress plugin stuck in a loop, one traffic spike or one hacked site can slow down — or expose — every other account on the box. CloudLinux OS, built on the same enterprise Linux base as AlmaLinux, changes that at the kernel level.

    Each account runs inside a Lightweight Virtual Environment with its own limits, sees only its own files through CageFS, and can choose its own PHP version without touching anyone else. XcellHost supplies the licence for your server — ours or anyone's — installs or converts the OS, sets sensible limits and supports it 24×7 from Mumbai.

    How LVE works

    Seven limits per account — enforced by the kernel, not by hope.

    LVE (Lightweight Virtual Environment) wraps every hosting account. When an account reaches a limit it is slowed or refused — it does not take the server with it. Defaults below are CloudLinux's out-of-the-box values; XcellHost tunes them per package.

    What happens at a limit (per CloudLinux): CPU and I/O are throttled, not killed; too many entry processes returns a "508 Resource Limit Reached" page to that site only; memory and process limits stop new work inside that one account.

    SPEEDCPU, as a share of one core default 100%
    PMEMPhysical memory default 1,024 MB
    IODisk throughput default 1,024 KB/s
    IOPSDisk operations per second default 1,024
    EPEntry processes — concurrent PHP, SSH, cron default 20
    NPROCProcesses & threads default 100
    InodesFiles & folders via disk quota set per package

    LVE resource limits

    CPU, memory, I/O, IOPS, entry-process and process limits for every account or hosting package.

    CageFS

    A virtualised file system per user — other accounts, their config files and most system tools are simply invisible.

    SecureLinks

    Kernel-level symlink protection against the classic "link to another user's wp-config" attack.

    Reseller limits

    Cap the total resources a reseller and all their customers can use — on the Unlimited edition.

    PHP Selector

    Each account picks its own PHP version and extensions from the panel, without a server-wide change.

    HardenedPHP

    Security fixes back-ported to older PHP versions, so a legacy app can keep running while you plan its upgrade.

    Python, Node.js & Ruby selectors

    Per-account app runtimes on cPanel and DirectAdmin; Ruby is not in the 1-account edition.

    mod_lsapi PRO

    An Apache PHP handler that serves PHP faster with less memory than suPHP or plain CGI.

    MySQL Governor

    Tracks database CPU and I/O per account and restricts the account that is overloading MySQL or MariaDB.

    Per-account throttling

    Restricted accounts are slowed in steps, then released automatically when usage settles.

    Database usage history

    See which account caused the slow-down last night instead of guessing from the slow-query log.

    Slow site analyzer

    Website monitoring
