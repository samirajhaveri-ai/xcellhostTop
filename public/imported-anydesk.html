    Overview

    Remote access that feels local — bought and supported in India.

    AnyDesk is remote desktop software for IT teams, help desks and service providers. A technician opens a session to any PC, Mac, Linux machine, server or phone using its AnyDesk address — no port forwarding or firewall changes for the usual setup. Sessions are encrypted, and the user either accepts each request or the device is set up for unattended access with a password and two-factor authentication.

    XcellHost is your local AnyDesk partner. We help you pick the right edition, issue the licence on an INR GST invoice, set up my.anydesk users, address books, permission profiles and a custom client, roll it out to your devices, and support your technicians from Mumbai.     How a session connects

    Four checks between a technician and a screen — in about a second.

    A simplified view of an attended or unattended AnyDesk session. Timings are illustrative.

    1. 01
      Request

      The technician enters the device's AnyDesk address or picks it from a shared address book.

    2. 02
      Consent or unattended check

      The user clicks Accept — or, for an unattended device, a password and 2FA code are checked against its access control list.

    3. 03
      Encrypted channel

      TLS 1.3 with AES-256 transport encryption, verified by RSA-2048 key exchange, per AnyDesk.

    4. 04
      Screen streams back

      DeskRT sends screen changes; permission profiles decide if the technician may control, transfer files, print or record.

      Security & good practice

      Only the right people connect — and only with permission.

      AnyDesk gives you the controls. XcellHost sets them up with you so they're on from day one.

      Consent on attended sessions

      The user sees who is connecting and clicks Accept. Permission profiles limit what a technician can do.

      2FA for accounts and unattended access

      Time-based one-time codes for my.anydesk sign-in and for unattended connections.

      Harden unattended devices

      Long unique passwords, access control lists, disabled interactive access where not needed, and regular review of who has access.

      Session recording & logs

      Record sensitive sessions and keep session history for audit — useful for ISO 27001 and client reviews.

      Privacy mode

      Blank the remote screen while a technician works on payroll, banking or patient data.

      India: DPDP & CERT-In

      Least-privilege access and audit trails help you meet DPDP Act duties and keep logs ready for CERT-In requests.

      Never let a stranger connect.

      Banks, telecom companies, tax offices and courier firms will not ask you to install remote software. If an unknown caller asks for your AnyDesk address, hang up. XcellHost can turn on access control lists and disable incoming requests on staff PCs so this can't happen by mistake.

      FAQ

      AnyDesk in India, answered.

      AnyDesk is remote desktop software. Each device has an AnyDesk address; a technician enters it (or picks it from an address book), and the session opens once the user accepts — or, for unattended devices, once the password and 2FA code are checked. Typical setups need no port forwarding or firewall changes.

      Per AnyDesk, Standard covers up to 20 users, 1 to 20 concurrent connections and 500 managed devices, with a branded client and REST API. Advanced covers up to 100 users, 2 to 50 connections and 1,000 managed devices, and adds MSI mass deployment, full Group Policy and command-line control, role management and phone support.

      One remote session running at a time. The number of connections sets how many sessions your team can run at once — separate from how many users or devices you have. Standard and Advanced can add connections without changing edition.

      AnyDesk states it uses TLS 1.3 with AES-256 transport encryption and RSA-2048 key exchange, plus two-factor authentication, access control lists, permission profiles, privacy mode and session logs. Security also depends on set-up, so XcellHost configures 2FA, ACLs and strong unattended passwords with you.

      Yes — that is unattended access. Solo covers 100 managed devices, Standard 500, Advanced 1,000 and Ultimate 2,000, per AnyDesk, with add-ons for more. We recommend 2FA and an access control list on every unattended device.

      When you need single sign-on, an on-premises deployment, CRM or ITSM integrations, role-based address books without limits or more than 1,000 managed devices. Ultimate starts with five licensed users and is quoted per requirement.
