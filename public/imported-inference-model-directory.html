    Overview · man models

    A reference shelf for open models — read the entry before you run it.

    Open-weight models differ in size, languages, context length and, importantly, licence. This directory puts the facts that decide a deployment on one page, then links straight to the way you run each model on XcellHost.

    Each entry covers a model family and the exact versions XcellHost plans to offer: who publishes it, how many parameters it has, how much text it can read at once, what it is typically used for, and the licence it ships under. Where a fact is not published clearly by the model's creator, we leave the field blank rather than guess.

    When you are ready to build, every entry links to the Model Catalog to try it, to Serverless Inference to call it per token, or to Dedicated Inference to run it on your own NVIDIA GPUs. All three run in XcellHost's Mumbai cloud, so prompts and outputs stay in India — useful for DPDP Act obligations and for BFSI, healthcare and public-sector buyers.

    From entry to endpoint

    Five steps from "which model?" to a working API call.

    Scroll through one real example — Llama 3.1 8B Instruct for a support assistant — and watch the entry turn into a running endpoint.

    01 · find

    Search the directory by task, language or size

    Type what you need — "support bot, Hindi, low cost" — or filter by modality. Shortlist two or three entries rather than chasing the largest model.

    02 · licence

    Read the licence before you build

    Llama 3.1 ships under Meta's community licence: commercial use is allowed, with an acceptable use policy and extra terms above 700 million monthly users. Check every licence for your own use; this page is not legal advice.

    03 · size

    Estimate the GPU memory it needs

    Parameters × bytes per weight gives the memory for weights: 8B at FP16 (2 bytes) is about 16 GB, at INT4 about 4–5 GB. Add room for the KV cache, which grows with context length and concurrent users.

    04 · route

    Choose serverless or dedicated

    Serverless: shared GPUs, pay per token, nothing to manage — good for starting out or spiky traffic. Dedicated: your own L4, RTX Pro 6000 or H200 GPUs for steady volume, custom weights or private networking.

    05 · call

    Call it with the OpenAI-style API you already know

    Point your existing OpenAI SDK at XcellHost's endpoint, set the model name, and your prompts are processed in Mumbai. Swap models later by changing one string.
