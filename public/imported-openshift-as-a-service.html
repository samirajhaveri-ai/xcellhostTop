    Overview

    Kubernetes with the parts you would build anyway — and a team to run it.

    Red Hat OpenShift is an enterprise Kubernetes platform. On top of upstream Kubernetes it adds Red Hat Enterprise Linux CoreOS on every node, an installer, over-the-air cluster upgrades, a web console, Operators, an image registry, monitoring, and — depending on the edition — CI/CD, GitOps, a service mesh and virtual machines. It runs the same way in a data centre, on bare metal and on the major public clouds.

    The platform still needs people: someone to keep etcd healthy, plan upgrades, renew certificates, patch, back up and answer the 3 a.m. alert. With XcellCloud OpenShift as a Service, XcellHost builds and operates the cluster — in our Mumbai Tier IV data centre, on dedicated nodes, or on AWS and Azure — and your developers get namespaces, pipelines and a GitOps repo on day one.
