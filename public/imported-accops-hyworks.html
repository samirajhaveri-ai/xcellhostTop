    Overview · Accops HyWorks

    Desktops and apps that live in the data centre — screens that travel to any device.

    Accops HyWorks is the application and desktop virtualisation part of the Accops Digital Workspace suite. A single HyWorks Controller holds users, entitlements and policies, and hands each person a shared hosted desktop, a personal virtual desktop or just the published apps they need — on Windows or Linux.

    XcellHost builds and runs it for you. We host session hosts and desktop VMs in our Mumbai cloud, or install HyWorks on your own hypervisor, then look after gold images, app publishing, profiles, patching and 24×7 monitoring. You pay per user per month in rupees, on one GST invoice.

    How it works

    Five layers, one request — and only pixels come back.

    A typical XcellHost-hosted layout. Each packet is a user connecting; the controller picks the pool, the session team picks the least-busy host.

    01Connect

    A HyWorks client, a HyDesk thin client or a browser via HyLite registers with the controller.

    02Check

    Directory sign-in, plus HySecure and HyID if you add them, then the controller reads the user's entitlements.

    03Place

    Shared pool? The session team sends the session to the least-busy host. Personal pool? The user gets their own VM.

    04Work

    Apps, files and databases stay in the data centre; the device only receives the screen.
