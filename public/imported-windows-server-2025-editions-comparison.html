At a glance

One operating system, four sets of rights. The licence decides what you may run.

Standard, Datacenter and Azure Edition share the same Windows Server 2025 core. The differences are how many virtual machines one licence covers, which storage, networking and security features are switched on, and where the edition may run. Essentials is a small-business server licence sold only with new hardware.

Windows Server 2025 · what's new

Fewer restarts, faster storage, and features that used to be Azure-only.

The changes Microsoft documents for Windows Server 2025 that matter most when you choose an edition.

See them in the table
Hotpatch on Standard & Datacenter

Through Azure Arc, security updates install without a restart. Microsoft now lists Arc-enabled Hotpatch for 2025 at no extra cost. Azure Edition has it on by default.

SMB over QUIC in every edition

The SMB over QUIC server, once Azure Edition-only, now ships in Standard and Datacenter: file shares over the internet without a VPN.

Active Directory: 32k pages

A new functional level (level 10) and an optional 32k database page: multivalued attributes hold about 3,200 values, 2.6× more.

Faster NVMe storage

Microsoft reports higher IOPS and lower CPU use for NVMe in 2025, plus thin-provisioned volumes in Storage Spaces Direct.

GPU partitioning, live migration

Share one GPU across VMs and live-migrate them. Clustered high availability for GPU-P VMs needs Datacenter; Standard supports standalone hosts.

Bigger Hyper-V

Hosts up to 4 PB of memory and 2,048 logical processors; Gen 2 VMs up to 240 TB and 2,048 virtual processors.

256 TB4 PB
Credential Guard on by default

Enabled by default on devices that meet the requirements, protecting credentials from theft.

Azure Arc built in

Azure Arc Setup is installed by default, and Windows Admin Center manages servers from the Arc portal.

      Licensing explained

      Cores, CALs and SALs. Six rules that decide the bill.

      Standard and Datacenter are licensed by physical core, plus access licences for the people who connect. Here is how Microsoft's rules work out on a hosted server.

      01

      The core model

      License every physical core: at least 8 per processor and 16 per server. Core licences come in 2-packs and 16-packs. Essentials is one server licence instead: one socket, up to 10 cores.

      Applies to: Standard, Datacenter
      02

      CALs

      Each user or device that accesses the server needs a Windows Server CAL. Not needed for public web workloads or access by another licensed server. 2025 CALs cover earlier versions too.

      Applies to: Standard, Datacenter
      03

      Remote Desktop

      Remote Desktop Services needs an additive RDS licence for each user on top of the base access licence. On XcellHost SPLA this is a monthly per-user SAL.

      Indicative: ₹699* / user / month
      04

      SPLA, monthly via XcellHost

      Microsoft's Services Provider License Agreement lets us rent you Standard or Datacenter each month with the server. Nothing upfront; change cores when the server changes.

      Best for: hosted servers, changing workloads
      05

      Bring your own + Software Assurance

      SA adds step-up from Standard to Datacenter, disaster-recovery rights, new version rights and the Flexible Virtualization Benefit. OEM licences must join SA within 90 days of purchase. We check your agreement before go-live.

      Best for: firms with EA / MCA agreements
      06

      Azure Hybrid Benefit

      With SA, run your own Windows Server licences on Azure VMs and pay only for the base compute. Azure Edition is open to SA, Windows Server subscription and cloud customers.

      See: Managed Azure

      Upgrade paths & lifecycle

      Jump four versions in one go. Supported into 2034.

      From Windows Server 2025, a non-clustered server can upgrade in place up to four versions at a time, so 2012 R2 and later go straight to 2025. Clusters use a rolling upgrade, one version at a time.
