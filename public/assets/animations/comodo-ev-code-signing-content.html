Overview

Prove who built the software, and that nobody touched it since.

A code signing certificate puts a digital signature on your installers, executables, libraries, drivers, scripts and macros. When someone downloads your file, Windows and other platforms check two things: who signed it, and whether a single byte has changed since. Pass both and users see your verified company name instead of a yellow "Unknown publisher" warning.

Extended Validation (EV) is the strictest level. It's only issued to registered organisations, after checks on legal existence, operating history, address and authority. Comodo's CA business now runs as Sectigo — same roots, same infrastructure. XcellHost sells it in India with MCA and GST-based validation help, a hardware token couriered to your office, and SignTool or jarsigner setup on your build machines.

Sign, timestamp, ship

SignTool hashes the file, the token signs the hash, and a timestamp server records when. On install, Windows checks all three.

  • SHA-256 file digest
  • RFC 3161 timestamp
  • Verified name in the prompt

EV vs Standard (OV)

Same cryptography. Different depth of proof.

Both certificates sign the same file types with the same key strength. EV is for registered organisations that want the most thoroughly checked identity — and it's required for some driver workflows.
