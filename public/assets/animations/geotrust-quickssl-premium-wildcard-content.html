Assurance & authentication

Prove the whole domain is yours. Every subdomain is covered.

Because a wildcard speaks for every host under the domain, control has to be proved at the domain level — by DNS or an admin email, never a file on one website.

Wildcards in India

More subdomains, more exposure — regulators expect all of it encrypted.

No Indian rule names a certificate brand. Every framework does expect data in transit protected and certificates tracked — a wildcard turns many assets into one.

DPDP Act, 2023

Anyone handling personal data must take reasonable security safeguards. Every login, form and API on every subdomain should be encrypted — new ones from day one.

CERT-In directions

Cyber incidents, including website compromise, must be reported within six hours. Forgotten subdomains with expired certificates are a common way in.

RBI & SEBI entities

Regulators expect strong encryption on customer channels and an inventory of critical assets — certificates and expiry dates included.

MeitY & public sector

Government web guidelines expect sites served over HTTPS. XcellHost is MeitY-empanelled and installs certificates for public-sector hosting.

ssl_certificate     /etc/ssl/wildcard_chain.crt;

# 3 · test + reload
