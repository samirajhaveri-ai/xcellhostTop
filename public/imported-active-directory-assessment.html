Overview

Most networks have one directory. Few have looked at it end to end.

Active Directory decides who can sign in to almost everything: file servers, ERP, email, VPN, and through Entra Connect, Microsoft 365. It grows by accretion. People leave but their accounts stay enabled, helpdesk staff are added to admin groups "for a week", and settings chosen for Windows Server 2008 are still in force.

XcellHost Active Directory Assessment is a fixed-scope, read-only review of one forest. We collect configuration and membership data from a domain-joined host, check it against CIS benchmarks and Microsoft's guidance, and map privileged access into the control, management and user planes of Microsoft's enterprise access model. You get ranked findings, a fix plan grouped by effort, and one retest*.

Why it matters

Identity is now the usual way in. The directory is where it ends.

Incident reports worldwide keep pointing to the same pattern: a stolen or guessed credential, then a climb through over-privileged accounts until someone controls the directory. Ransomware crews value domain admin rights because they unlock every server at once.

Admin groups that only grow

People get added for a project and never removed. Nested groups hide who really has rights.

Accounts nobody owns

Leavers, test users and old service accounts stay enabled, often with passwords that never expire.

Settings from another decade

Legacy authentication, weak encryption types and old functional levels kept "for compatibility".

Hybrid means shared fate

Through Entra Connect, a weak on-premises directory can affect Microsoft 365 sign-in as well.

What we assess

Twelve areas of one forest, every domain and DC in it.
