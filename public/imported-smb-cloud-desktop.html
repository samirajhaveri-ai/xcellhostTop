    Overview

    Your office PC, moved to the cloud. Your team just logs in.

    Many small businesses still run on a few office PCs and one "server" machine that holds Tally, shared folders and Excel files. Branches connect over a patchy VPN, staff carry data home on pen drives, and nobody has tested the backup.

    SMB Cloud Desktop gives each user a Windows desktop on XcellHost's servers in Mumbai. Apps are installed once, company data stays in the data centre, and staff open the same desktop from any device. XcellHost runs the servers, patching, security and backups — you pay a fixed amount per user each month.

    How it works

    Sign in, work, log off. We run everything behind the screen.

    01 · Sign in

    Secure gateway with MFA

    Users open the Windows App or a browser link. The gateway checks the password and a one-time code before any desktop opens.

    • Encrypted Remote Desktop or HTML5
    • Optional office IP allow-lists
    • Idle session time-outs
    02 · Work

    Desktops on Mumbai servers

    Lite and Standard users get a private desktop on shared Windows Server session hosts. Pro users get a dedicated desktop server.

    • Apps installed once for everyone
    • Monthly patching and antivirus
    • Monitored 24×7 by our NOC
    03 · Protect

    Files stay on the server

    Tally data, shared folders and documents live on the file server, with nightly copies to a backup vault in India when you add backup.

    • 30 daily restore points (add-on)
    • File, folder or desktop restores
    • Logs kept 180 days in India
