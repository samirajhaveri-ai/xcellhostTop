Overview

Sectigo SSL Multi-Domain/UCC — 3 names included · up to 250 SANs.

Sectigo SSL Multi-Domain/UCC is a domain-validated (DV) certificate that carries several different domain names — up to 250 — as Subject Alternative Names (SANs). It started life as the Unified Communications Certificate for Microsoft Exchange and Office Communications, and is just as useful for a company running sites on .in, .com and .co.in.

The price includes 3 names (1 + 2 SANs); each extra domain is ₹ 3,108.00/yr. on a 1-year term down to ₹ 2,486.40/yr. on 5 years. Each name is validated separately, then the certificate is issued straight away with a US$500,000 warranty, unlimited server licences and reissues. XcellHost collects the approvals, installs it and reissues when you add names.
