    Reference architecture

    HA across Mumbai zones. DR to Delhi.

    The pattern we start from for a production S/4HANA system on Google Cloud. It draws itself — hover a layer to see what it does.

    • Private connectivityCloud VPN or Interconnect from offices and plants; internal load balancer for SAP traffic.
    • App tier in two zonesPrimary and additional app servers spread across Mumbai zones; ASCS/ERS in a Pacemaker cluster.
    • SAP HANA HAHANA system replication (synchronous) between zones with automatic failover.
    • BackupsHANA backups to Cloud Storage via Backint, plus disk snapshots — restores tested.
    • DR to DelhiAsynchronous replication to a right-sized DR system in the second India region.
    • Monitoring 24×7Cloud Monitoring and SAP-level checks feed the XcellHost NOC; logs kept for CERT-In.

    Reference pattern for illustration. Final design depends on your SAP products, sizes, RPO/RTO targets and the machine types certified for SAP in each region at the time of build.
