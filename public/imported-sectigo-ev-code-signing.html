Overview

The strongest certificate for user trust — your company, proven, on every file.

A code signing certificate puts a digital signature on your executables, installers, drivers, scripts and macros. The signature tells Windows, browsers and antivirus tools two things: who published the file, and that not a single byte has changed since it was signed. Without one, users see "Unknown Publisher" — and many simply cancel the install.

Sectigo EV Code Signing is the extended-validation tier: only registered organisations qualify, and Sectigo checks legal existence, operational history, address and phone before issuing. It is the level Microsoft requires for kernel-mode drivers. XcellHost prepares your MCA or GST documents, ships the FIPS-certified USB token within India (or sets it up on your HSM), and helps wire signing into your build.

      Where EV matters most

      Drivers, enterprise rollouts, and customers who check who you are.

      Standard (OV) code signing covers most apps. These three situations are where EV is either required or clearly worth it.

      Drivers need EV — Microsoft requires it

      Windows 10 and 11 only load kernel-mode drivers that Microsoft has signed. To submit a driver to the Windows Hardware Dev Center you first register with, and sign your submission using, an EV code signing certificate. Microsoft then attestation-signs (or WHQL-signs) the package.

      Policy notices

      Three rule changes every code signer should know.

      Code signing rules have tightened since 2023. Here's what changed, and what it means when you order today.

      Today
      June 2023

      Keys must live on hardware

      CA/Browser Forum rules now require every code signing key — OV and EV — to be generated and stored on a FIPS 140-2 Level 2 / Common Criteria EAL4+ token or HSM.

      For you: no more .pfx files. We courier a certified USB token or set up your HSM.

      March 2024

      SmartScreen treats EV like reputation

      Microsoft stopped instantly suppressing SmartScreen warnings for EV-signed files. EV is still the highest assurance level, but reputation now builds with downloads for every certificate.

      For you: sign consistently with one identity and reputation accumulates faster.

      February 2026

      One-year certificates

      New orders are limited to 1-year validity. HSM-based orders can still be bought for up to 3 years, with a reissue each year to get a fresh maximum-validity certificate.

      For you: token plans are yearly; multi-year savings need an HSM.
