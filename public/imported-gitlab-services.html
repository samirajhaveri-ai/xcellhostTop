What you get in GitLab

One application from commit to production. We set up every part.

GitLab puts source control, CI/CD, security scanning, compliance and package registries in one place. Here is what each part does and what XcellHost configures for you.

Pipelines defined in .gitlab-ci.yml

Stages, jobs, merge-request pipelines, parent-child pipelines and environments with approvals. Jobs run on runners: GitLab's hosted runners on GitLab.com, or your own runners anywhere.

  • GPU runners for ML training and inference tests, priced on quote

Find issues before they merge

GitLab runs scanners in the pipeline and shows the results in the merge request. Basic SAST and secret detection work on every tier; the full set, with the vulnerability report and security policies, is part of Ultimate.

  • Static analysis (SAST) and secret detection
  • Dependency and container scanning
  • Dynamic testing (DAST) and API security testing
  • Merge request approval policies to block risky changes

Audit events, protected branches, required approvals, compliance frameworks and compliance pipelines help you show auditors a controlled process. Many of these controls are Premium or Ultimate features.

  • Protected branches, code owners and approval rules
  • Compliance frameworks applied to projects
  • Supports RBI, SEBI and DPDP evidence requests when hosted in India

We follow GitLab's reference architectures. Up to 20 requests per second, about 1,000 users, runs on one node with 8 vCPU and 16 GB memory, which we place on a G1.2xlarge at ₹9,599 a month.
