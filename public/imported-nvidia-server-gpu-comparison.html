Glossary

Spec-sheet words, in plain English.

SXMSocketed module

A GPU module that mounts flat on a baseboard such as HGX instead of a PCIe slot. It allows higher power and connects every GPU over NVLink — the form factor for B300, B200, H200 and H100 training systems.

NVLinkGPU-to-GPU link

NVIDIA's high-speed link between GPUs. Per NVIDIA, fifth-generation NVLink gives each Blackwell GPU 1.8 TB/s; Hopper SXM gets 900 GB/s. PCIe cards use a bridge for two or four GPUs, or none.

NVL72Rack-scale domain

A liquid-cooled rack with 72 GPUs and 36 Grace CPUs in one NVLink domain, so the rack behaves like one giant GPU. GB200 NVL72 and GB300 NVL72 are built this way.

HBMHigh-bandwidth memory

DRAM stacked beside the GPU die. HBM3e and HBM4 deliver terabytes per second, which sets how fast large models generate tokens. PCIe cards such as L4 and RTX PRO use GDDR6 or GDDR7 instead.

MIGMulti-Instance GPU

Splits one GPU into isolated instances, each with its own memory and compute — for example up to seven on H200 or four 24 GB slices on RTX PRO 6000. Useful for many small models or tenants.

Transformer EngineMixed-precision engine

Hardware and software that pick FP8 (Hopper) or FP4 (Blackwell) per layer while keeping accuracy. Per NVIDIA, it is why newer GPUs serve transformers far faster at the same memory.

FP4 · NVFP44-bit floating point

Four bits per weight — a quarter of FP16. Blackwell and Rubin run it natively; NVFP4 is NVIDIA's scaled FP4 format. A 70B model's weights drop from about 140 GB at FP16 to about 35 GB.

Sparsity2:4 structured sparsity

If two of every four weights are zero, Tensor Cores skip them and double throughput. NVIDIA's headline figures are usually "with sparsity"; dense figures are half unless NVIDIA states otherwise. This page labels both.
