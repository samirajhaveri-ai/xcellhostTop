    Overview

    SSL that installs itself — on servers you control.

    For dedicated servers, VPS and cloud VMs where you have root or administrator access. Shared hosting and control panels use our Web Hosts plugin instead.

    The problem is not buying a certificate — it is everything after. Someone has to generate a CSR, copy a validation file or DNS record, wait for the CA, install the certificate with the right chain, reload the web server and set a reminder for next time. With certificates now limited to 200 days and heading to 47, that “next time” comes round several times a year for every site on every server.

    AutoInstall SSL hands that loop to an agent. You run one command on the server. The agent finds your Apache, Nginx or IIS sites, creates the key on the server, completes domain validation by file or DNS, installs and verifies the certificate, then checks every day and renews 28 days before expiry. XcellHost does the setup, watches agent health from its Mumbai NOC and invoices you in INR with GST.

    Works with AApache NNginx IIIS UUbuntu DDebian CCentOS WWindows Server AWS EC2 Azure VMs

    Tomcat, HAProxy, LiteSpeed, load balancers and Exchange aren’t handled by the agent — our engineers install those through the SSL Installation Service.

    Why now

    Lifetimes are shrinking. Renewals are multiplying.

    CA/Browser Forum Ballot SC-081v3 cuts the maximum life of a public TLS certificate in three steps. Today (October 2026) we are in the 200-day phase.

    Before 15 Mar 2026398 days1× / yr
    From 15 Mar 2026200 days2× / yr
    From 15 Mar 2027100 days4× / yr
    From 15 Mar 202947 days8× / yr

    Domain-validation reuse falls on the same dates — 200 → 100 → 10 days from 2029. Renewals per year = 365 ÷ maximum life, rounded up. Applies to publicly trusted TLS only. Source: cabforum.org.

    Ten servers with five sites each is 400 manual renewals a year by 2029. With the agent it is none.

    Let’s Encrypt is moving the same way — 45-day certificates by default from February 2028, and it recommends ACME Renewal Information (ARI, RFC 9773) so clients know when to renew. More on the 47-day timeline: 47-Days-SSL.
