    Per cloudflare.com/plans, in USD: Free is US$0; Pro is US$20 a month billed annually or US$25 monthly; Business is US$200 a month billed annually or US$250 monthly; Enterprise is a custom contract. Cloudflare One has a Free plan and Pay-as-you-go at US$7 per user a month. Through XcellHost, Cloudflare is quoted — we do not convert list prices to rupees.

    They were renamed on 17 February 2026: Cloudflare WAN, Cloudflare Network Firewall and Network Flow. The Magic WAN Connector became the Cloudflare One Appliance and Magic Cloud Networking became Multi-Cloud Networking. Cloudflare says configurations and billing did not change. Magic Transit kept its name.

    Page Shield is now Client-Side Security, Firewall for AI is AI Security for Apps, Browser Rendering is Browser Run, AutoRAG is AI Search, the Zero Trust WARP client is the Cloudflare One Client, and Pipelines, R2 Data Catalog and R2 SQL now sit in Basin. Each row shows its former name, and search finds the old names too.

    Cloudflare Mesh for private networks between users, servers and AI agents (April); Artifacts, Git-compatible storage (beta, April); Basin, the analytics platform, generally available, and K2 event streams in beta (both October); plus agent tools such as Agent Memory, Web Search API, Monetization Gateway and Cloudflare Wallets, listed in Cloudflare's documentation.

    Cloudflare's SASE and Zero Trust platform: Access, Secure Web Gateway, the Cloudflare One Client, Tunnel, Mesh, Browser Isolation, CASB, DLP, Email Security and Digital Experience Monitoring, with Cloudflare WAN and Network Firewall for sites. It replaces VPNs and backhauled branch traffic.

    Cloudflare's Data Localization Suite controls where it inspects traffic and stores logs and keys; which regions you can pick depends on your contract, so we confirm it before you buy. For India-only hosting of the origin itself, XcellHost runs your servers in Mumbai.
