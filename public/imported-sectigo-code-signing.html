Overview

A digital signature on everything you ship, so users know it came from you.

A code signing certificate lets you put a digital signature on executables, installers, drivers, scripts and macros. When someone downloads your file, their operating system reads that signature to answer two questions: who published this, and has it changed since it was signed? Change a single byte and the signature breaks. Signed files show your verified name instead of the “Unknown publisher” warning that makes users cancel installs.

The Sectigo OV certificate is organisation-validated: Sectigo checks a registered business — or, unusually, an individual developer — before issuing. Under current industry rules the private key is created and kept on a FIPS-certified hardware token or HSM, never on a laptop. XcellHost handles the validation with your MCA, GST or ID documents, couriers the token anywhere in India and helps you wire signing into your build.

How it works

Hash, sign, verify. Three steps, every release.

Signing doesn't change what your software does. It attaches a sealed fingerprint that any Windows, Java or Office installation can check in milliseconds.

01 · Hash
setup.exe9f2c 41ab 07de 88c3

Your build gets a fingerprint

A SHA-256 hash is calculated over the whole file. It's unique to those exact bytes — any edit produces a completely different hash.

  • SHA-256 digest of the file
  • Runs in SignTool, jarsigner & more
  • Takes milliseconds per file
02 · Sign on token

The token signs the hash

The hash goes to your USB token or HSM, you enter the PIN, and the private key signs it inside the hardware. The key itself never leaves.

  • 3072-bit RSA private key
  • PIN-protected, non-exportable
  • RFC 3161 timestamp added
03 · Verify on install
Verified publisherYour Company Pvt Ltd

Users see your name

On download or install, Windows re-hashes the file and checks it against your signature and Sectigo's chain. Match: your name. Mismatch: blocked.

  • Publisher name in UAC prompt
  • Tampering detected instantly
  • Still valid after expiry, if timestamped
