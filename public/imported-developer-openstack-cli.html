    Overview

    The OpenStack CLI (python-openstackclient) is the official command-line client for OpenStack clouds — and XcellCloud is one. Install it with pip, save your application credential in a clouds.yaml file or an openrc script, and every XcellCloud resource in region mumbai-1 is a single openstack command away: servers, flavors, images, keypairs, networks, subnets, routers, security groups, floating IPs and volumes.

    Add the python-octaviaclient plug-in for load balancers. Every command can print a table for people or JSON, YAML, CSV or bare values for scripts, so the same tool runs ad-hoc fixes at 2 a.m. and nightly jobs in cron or CI.     Security · keep secrets out of history, logs and git

    Application credentials

    Authenticate the CLI with an app credential scoped to one project — not your console password.

    Split clouds.yaml

    Keep the secret in secure.yaml, separate from clouds.yaml, so the config can be shared safely.

    Lock file permissions

    chmod 600 both files so other users on the machine cannot read them.

    Never commit secrets

    Add clouds.yaml, secure.yaml and *-openrc.sh to .gitignore; use CI secret variables.

    Nothing secret on the command line

    Flags like --os-application-credential-secret land in shell history — prefer files or env vars.

    Rotate & expire

    Give every credential an expiry, rotate it on a schedule and delete the old one.

    MFA on the console

    Protect the people who can create credentials with multi-factor sign-in.

    Data stays in Mumbai

    Everything you create with --os-region-name mumbai-1 runs in India, supporting your DPDP Act obligations.

    Plug-ins
    Extend the CLI with one pip install.
    Plug-ins add command groups to the same openstack binary. Install only what your XcellCloud project uses.
    
    
    python-octaviaclient
    Adds openstack loadbalancer … — load balancers, listeners, pools, members and health monitors.
    Included
    python-heatclient
    Adds openstack stack … for orchestration templates.
    Where enabled
    python-designateclient
    Adds openstack zone … and recordset … for DNS-as-a-service.
    Where enabled
    python-barbicanclient
    Adds openstack secret … for a key manager service.
    Where enabled
    
    
    Plug-ins marked “where enabled” work only if that service is in your project's catalog — check with openstack catalog list or ask us.
