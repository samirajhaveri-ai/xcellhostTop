What it is

A SIEM collects and correlates security logs. A next-gen SIEM does it at cloud scale, as code.

The job hasn't changed: gather events from every system, find the attacks hidden in them, and give analysts one place to investigate. What changed is how much data there is, where it lives and how fast teams need to act.

AreaLegacy SIEMNext-gen SIEM (XcellSecure)
PlatformAppliances or VMs you size, patch and scaleCloud-native service; capacity grows with ingest
StorageOne expensive hot store; old data archived offlineAnalytics tier for detection + low-cost data lake, still queryable
Data modelPer-vendor parsers; queries rewritten for each sourceNormalised schema (ASIM in Sentinel); one query across vendors

Who needs one?

Any organisation that must keep and review logs — CERT-In asks every service provider, intermediary, data centre and body corporate to keep ICT logs for 180 days in India — and anyone outgrowing an on-premises SIEM's storage bill.

What it is not

Not a replacement for EDR or NDR. A SIEM sees what other tools log; EDR and NDR generate the deep endpoint and network signal it correlates.

Why managed

The platform is half the work. Tuning, hunting, triage at 3 a.m. and the CERT-In call are the other half — that's what our 24×7 SOC does.

Why it matters in India

Four rulebooks expect logs, monitoring and fast reporting. An NG-SIEM is how you prove it.

General information, not legal advice. Your regulator's latest text prevails.

CERT-In directions · 28 April 2022
6 hto report specified cyber incidents
180 drolling ICT log retention, within India

Clocks synchronised to NIC or NPL time sources. We flag reportable incidents and build the evidence pack while the incident runs.

DPDP Act, 2023 & Rules, 2025

Reasonable security safeguards and breach intimation to the Data Protection Board and each affected person without delay, with a detailed report to the Board within 72 hours. Core duties apply from 13 May 2027. DPDP platform →

RBI · banks & regulated entities

RBI's 2016 Cyber Security Framework expects banks to run a Security Operations Centre for continuous monitoring, and later IT-governance directions keep that expectation for regulated entities.

SEBI CSCRF · 20 August 2024

SEBI-regulated entities must be monitored by a SOC — their own, a group SOC, a third-party managed SOC or the Market SOC run by NSE/BSE for smaller entities.

FAQ

NG-SIEM, answered.

Four things: it runs as a cloud service that scales with your data; it stores data in tiers so long retention is affordable; it normalises every vendor to one schema; and detection, behaviour analytics (UEBA) and automated response (SOAR) are part of the same platform. Detection-as-code and an optional AI assistant complete the picture.

Microsoft Sentinel by default — XcellHost is a Microsoft Gold Partner and Sentinel works natively with Defender XDR, Entra ID and Microsoft 365. If you already run Splunk*, Elastic*, Google Security Operations* or Wazuh*, our SOC can co-manage it or plan a migration.

Both are schemas that give security data common field names. ASIM (Advanced Security Information Model) is Microsoft Sentinel's normalisation layer, applied through parsers at query time or during ingestion. OCSF (Open Cybersecurity Schema Framework) is an open, vendor-neutral schema project under the Linux Foundation used by several other platforms; Google Security Operations uses its own Unified Data Model (UDM).

Each rule is a file in a Git repository with its query, ATT&CK tags, severity, owner and test data. Changes go through review, are tested against sample logs and are deployed to your workspace by a pipeline. You get history, rollback and the same rules across every tenant we run.
