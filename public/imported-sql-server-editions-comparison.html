At a glance

Four editions, one engine. The limits are what you pay for.

All four editions share the same SQL Server database engine and T-SQL. What changes is how many cores and how much memory the engine may use, how big a database can grow, and which high-availability and enterprise features you get. Switch the version to see how SQL Server 2025 moved the lines.

SQL Server 2025 · what changed

Bigger Standard, bigger Express, and no more Web edition.

SQL Server 2025 (17.x) is generally available. These are the edition changes Microsoft documents, compared with SQL Server 2022.

Standard: 24 → 32 cores

Database engine limit rises to the lesser of 4 sockets or 32 cores.

2432
Standard: 128 GB → 256 GB buffer pool

Twice the memory for cached data per instance.

128256
Express: 10 GB → 50 GB per database

And Express now includes what used to be "Express with Advanced Services".

1050
Web edition not available

Microsoft states Web edition isn't available in SQL Server 2025 and later. Web stays on 2022.

Resource governor in Standard

Previously Enterprise-only; the 2025 table lists it for Standard too.

Reporting → Power BI Report Server

On-premises reporting is consolidated under Power BI Report Server, available with Standard and Enterprise. SSRS 2022 is the last SSRS release.

Standard Developer edition

A free dev/test edition matching Standard, beside Enterprise Developer.

Windows Server 2019 or later

2025 supports Windows Server 2019, 2022 and 2025. Still on 2016? Stay on SQL Server 2022 or upgrade Windows first.

      Licensing explained

      Four ways to pay for SQL Server. One rule that catches everyone.

      The rule: per-core licensing counts every virtual core of the VM (or every physical core of the server), with a minimum of four core licences per VM or per processor. Microsoft sells core licences in 2-packs.

      01

      SPLA, monthly via XcellHost

      Microsoft's Services Provider License Agreement lets a hoster rent licences to you each month. Nothing upfront, scale cores up or down with the server, and the only route to Web edition.

      Best for: hosted servers, changing workloads
      02

      Bring your own (Licence Mobility)

      Already own Standard or Enterprise core licences with active Software Assurance? Licence Mobility through SA lets you run them on our shared cloud. Fail-over rights don't apply under Licence Mobility.

      Best for: firms with existing EA / SA
      03

      Per core

      Standard and Enterprise. Count cores, apply the 4-core minimum, buy 2-packs. No user counting. Licensing individual VMs needs Software Assurance or a subscription licence.

      Best for: web-facing or many-user systems
      04

      Server + CAL

      Standard only for new agreements: one server licence per OSE plus a CAL for each user or device. Enterprise Server + CAL is no longer sold for new agreements and is capped at 20 cores per instance.

      Best for: small, known user counts
