    Overview

    The control panel most web hosts run on — licensed and looked after by XcellHost.

    cPanel & WHM is two panels in one licence. WHM is the server owner's console: create hosting accounts, set packages and limits, manage resellers, run updates and backups. cPanel is what each account owner sees: a home screen of tiles for email, files, databases, domains, SSL and backups, so a site owner can manage hosting without a terminal.

    XcellHost supplies the licence for a server you already run — at any provider — or for an XcellHost VPS or dedicated server in Mumbai. We install it on a clean OS, harden it, move your sites across and stay on call 24×7. You pay in rupees on one GST invoice, and you can change tier as your account count grows.

    How licensing works

    One licence, one server IP — and you can change tier any time.

    The rules below are cPanel's; XcellHost handles the paperwork when anything changes.

    01
    Bound to your server's IP

    A licence is tied to the server's main public, static IPv4 address. Extra IPs on the same server need no extra licence, per cPanel.

    02
    VPS tiers vs dedicated

    Solo, Admin and Pro are for cloud/VPS machines. A dedicated (bare-metal) server needs Premier.

    03
    Upgrade or downgrade

    Change tier when your account count changes; cPanel prorates tier changes. XcellHost reflects it on your next INR invoice*.

    04
    New server or new IP

    Moving to a new server? We re-point the licence to the new IP during the migration window, so both servers can run while you cut over*.

    05
    Monthly or annual

    Licences renew on the billing date. Annual billing is cheaper per month; cancel before renewal to stop.

    Free certificates with AutoSSL

    AutoSSL issues domain-validated certificates for every domain and renews them automatically — Let's Encrypt is the default provider, included with the licence, per cPanel. It checks nightly and after each new account.

    Web firewall and brute-force protection

    ModSecurity filters malicious web requests; cPHulk and two-factor authentication slow down password guessing on cPanel, WHM and mail logins.

    Malware defence with Imunify360

    For servers hosting many sites, the Imunify360 add-on scans uploads, cleans infected files and blocks attacks at the server.

    Backups that live somewhere else

    WHM schedules account backups; XcellHost sends a copy off the server — for example to Acronis cloud backup — so a disk failure isn't a data loss.
