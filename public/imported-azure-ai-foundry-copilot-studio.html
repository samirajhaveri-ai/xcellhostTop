What is Microsoft Foundry?

One Azure platform to build, test and run AI agents.

Microsoft describes Foundry as a unified platform-as-a-service for building, deploying and managing AI apps and agents. It brings models, agent orchestration, knowledge, monitoring and governance into one Azure resource, so your developers and your security team look at the same thing.

What is Copilot Studio?

Low-code agents that live inside Microsoft 365.

Microsoft Copilot Studio is where business teams and makers design agents with topics, knowledge, tools and agent flows, then publish them where people already work. It is governed from the Power Platform admin center, the same place your IT team already manages apps and flows.

Advanced RAG in Foundry

Answers that come from your documents, with the page number.

Retrieval-augmented generation fetches the right passages before the model writes. Foundry IQ and Azure AI Search do this with hybrid search: keyword (BM25) and vector queries run side by side, Reciprocal Rank Fusion merges them, and an optional semantic ranker re-orders the top results.

  1. 01Multi-source data

    SharePoint, Azure SQL, Azure Storage, OneLake, the web and APIs, chunked and embedded into one index.

    Docs · DBs · APIs
  2. 02Hybrid search

    Keyword search catches exact terms like policy codes. Vector search catches meaning. Both run in one request.

    Vector + keyword
  3. 03Better context

    Filters (department, date, region), semantic reranking and agentic retrieval that plans sub-queries across sources.

    Filter · rerank · plan
  4. 04Reliable results

    Answers cite their sources and respect user permissions on supported sources, which reduces hallucination. It does not remove the need to test.

    Cited, permission-aware
